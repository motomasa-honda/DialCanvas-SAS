# ADR-0001: 旧構成と履歴を保存する

- 日付: 2026-10-08
- 状態: 採用

## 背景

旧リポジトリは 1 コミットの Draft 文書群で、実装コードがない。既存のパスは将来の参照に使われる可能性がある。

## 決定

旧資料の削除・移動を行わず、新しい Phase 0 資料を `docs/00-project/` などに追加する。空の製品ディレクトリは作らない。ルート README のみ現行の入口に更新する。

## 影響

旧 `docs/requirements/` と新 `docs/01-requirements/` が並存する。旧資料は履歴・Draft、新資料は現行要求として README に区別を明記する。実コードが後に見つかったら再評価する。
