# ADR-0005: 常時3.3Vの完成モジュール化とDC入力優先比較

- 登録日：2026-10-19
- 状態：代替回路候補を実装。最終部品採用・電源容量・製造は未承認。
- 基準：main統合コミット `40db88320368f24aea1782bf3714428e300b40fa`。

## 背景

ADR-0004の全体監査後、ユーザーは既製品優先、DCジャックを含む比較と設計継続を承認した。個別TPS62933電源の11部品を維持して設計を続ける前に、完成DC/DCを接続した回路を比較できる状態にする。

## 決定

1. Pololu D24V5F3 #2842を常時3.3Vの第一評価候補とし、VIN/GND/VOUT/SHDNという実端子名でKiCad代替回路を生成する。個別TPS62933候補は歴史原本として保存。
2. 元のG1-94安全回路618端子は変更せず、上流5VからAONを生成する。eFuse ENと28相OEの禁止状態も保持。
3. 外部源は5V/5A級DCアダプターを先に比較する。今回の比較品はMEAN WELL GST40A05-P1J。USB-Cも代替候補として残し、実負荷・電圧・コネクタ・保護が確定するまで最終選定しない。
4. 市販モーターAdafruit #858、独立ULN2003基板7枚、FIT0836暖色照明を全体予算へ含める。掲載値と概算を実測ピーク/保証最小値へ転用しない。
5. 原回路の数値ピンと異なり、モジュールは印字端子名で表現する。現物のヘッダー向きや番号を決めたとみなさず、フットプリントは空欄。

## 根拠と影響

[実装・予算・一次資料](../execution/cots_power/README.md) と `components.json` を参照。3A源の残り机上枠は約1.255A、5A源は約2.855Aだが、表示/外部AON/ドライバー等が欠測。いずれも容量合格ではない。完成モジュール出力の±4%・熱・起動・逆給電検証は残る。

原回路の供給源未実装のERC3件は旧版の履歴。新候補でVOUT電源出力を表現しても、外部入力・帰路・保護が未実装のためERCクリーンとはしない。G1-05/06の完了条件や実機停止条件を緩和しない。48件のID・状態・製造ゲートは変更しない。

## 代替案

- TPS62933個別回路の継続：完成モジュールの負荷/精度/形状が不適合なら再評価する。比較原本を消さない。
- USB-C 5A受電：契約・受電モジュール・電圧・接続形状が成立すれば再比較する。
- 3A源への即決：全負荷とピークが未確定なので採らない。
- 電流制限を上げて整合させる：既存eFuseの保証最小値・実機安全根拠がないため採らない。
