# ADR-0009: 3.4Cの給電・文字盤・ファームウェア基準を固定する

- 日付: 2026-10-21
- 状態: **文字盤/ファームウェアは設計基準。USB-C給電source部はADR-0014で置換済み**
- 置換: Pololu #3411のCC抵抗変更案はADR-0014のTPS25810EVM-745候補で置換。本文は2026-10-21時点の判断履歴。
- 関連: [ADR-0008](0008-one-off-cots-part-selection.md)、[調達候補BOM](../docs/02-architecture/unselected-parts-procurement-plan-2026-10-21.md)、[電源仕様](../docs/04-electronics/power-and-control.md)、[文字盤仕様](../docs/05-display/dial-file-and-rendering-design.md)

## 背景

一台限りの製作を想定し、既製品を優先して3.4型表示器へ安全に給電する接続と、ユーザーがPCで簡単に変更できる文字盤データを具体化する。3.4Cの背面40ピン端子の給電方向を公開資料から確定できなかったため、メーカーが電源用途を示すUSB-C入力を選ぶ。文字盤はmicroSDで交換し、時計針は機械歯車とは独立して画面上で滑らかに動かす。

## 判断

### 給電インターフェース

1. Waveshare ESP32-P4-WIFI6-Touch-LCD-3.4Cの`USB TO UART` Type-C入力を、通常運用時の表示基板給電口にする。40PIN拡張ヘッダーへの5V注入は設計に含めない。
2. 5V経路を **HUSB238 9V出力 → Pololu D24V50F5 #2851 → 画面枝ヒューズ → Pololu #3411 (usb07b) → 0.3m ELECOM MPA-XCCECSS03BK → 3.4C USB TO UART Type-C入力** とする。Pololu #2494は#2851出力線の着脱端子候補として維持する。
3. #3411は既製品を使うが、出荷時のCC1/CC2は5.11kΩ Rdを持つ受電側構成である。送電側に使うにはそのRdを切り離し、5V源として必要なRpをCC1/CC2へ設定する作業が要る。Rp値は、3.4Cの実改版が指定する入力条件、最大表示電流、照明負荷、9V/3A PDの総電力枠を測ってから決める。CCのRp表示は電流制限器ではないため、画面枝ヒューズを別途設ける。
4. 5V枝、9V枝のヒューズ値、線径、コネクター適合、PD契約、電圧降下、変換器/基板/木部の連続温度が未受入のため、部品選定は製作・通電の合格を意味しない。デバッグUSBとの同時接続を避ける。

### 文字盤と針表示

1. ユーザーは一般的な画像編集ソフトから800×800px、sRGB、Baseline JPEG（最大8MB）の`face.jpg`を作り、microSDの`DialCanvas/faces/<名前>/`へコピーする。microSDHC 8〜32GB、FAT32を使い、初号機ファームウェアは文字盤領域を読み取り専用で扱う。追加・削除時は電源を切ってカードをPCへ移す。
2. 各文字盤の任意ファイル`dial.json`（version 1）に、針の色・中心位置・長さ・太さを記す。スクリプトやパス等の実行可能設定は受け入れず、欠落/不正時は既定値を使う。ファームウェア内に削除できない既定文字盤を保持する。
3. NTP/RTC時刻と単調増加タイマーからフレームごとに秒・分・時針の角度を連続補間する。描画は60fpsを目標、実機の最低受入を30fpsとする。針は歯車の停止や速度に依存させない。
4. 文字盤は電源OFFのmicroSD編集と本体ロータリーエンコーダーで管理する。初号機にWeb管理は実装せず、Wi-FiはSNTP時刻同期に使う。
5. LVGL、ESP-IDF BSP、JPEGデコーダーは既製ソフトを利用するが、文字盤一覧、切替、連続針描画、操作、異常時の既定盤復帰を組み合わせる時計アプリケーションは専用実装する。
6. 針の移動方式は全文字盤で連続掃引に統一する。`dial.json`で変更できるのは針の見た目だけとし、文字盤ごとの刻み/連続の切替は設けない。旧要件FG-042はFG-045に置換する。

### ファームウェア基準と操作

1. 最初のビルド基準をESP-IDF v5.5.5、Waveshare managed BSP 3.0.1、LVGL 9系に固定する。メーカー公式LVGL 9デモが3.4CをESP-IDF v5.5.5/v6.0.2とBSP 3.0.1で扱うため、初回は同じ検証組合せのv5.5.5を使う。LVGLの解決済みパッチ版は実装時に依存ロックファイルへ固定する。
2. JPEGデコーダーはEspressif `espressif/esp_jpeg` 1.3.1を使用する。FATFS/SDIO、NVS、SNTP、cJSON、esp_timerはESP-IDFの標準機能を使い、独自フォーマット変換アプリや専用基板を追加しない。
3. エンコーダーを回して文字盤を移動、短押しで選択、長押しで装飾歯車を開始/停止する。モーター電源と暖色照明は独立した物理スイッチで切り替える。
4. 初号機に音声通知用スピーカーを追加しない。静音性は実際のモーター/歯車の音で評価する。

## 価格への影響

2026-10-21時点で、Pololu #3411は1個US$3.95、ELECOM MPA-XCCECSS03BKは¥1,430（税込）の表示。DS3231 #3013とCR1220の追加後、BOM全体の価格既知分は円建て約¥73,643（8mm PC板の標準価格換算¥8,756を含み、同板分を除くと約¥64,887）、輸入部品は画面/端子台/#3411の合計US$73.31。送料、為替、抵抗小部品、ヒューズ、工具、加工費は含まない。在庫・納期・表示価格は調達時に再確認する。[RTC判断と購入先](0011-external-ds3231-rtc.md)。

## 現物受入までの保留

- #3411のCC抵抗変更は、測定値に基づくRpと画面枝ヒューズを選び、極性・導通・短絡を無通電で確認してから行う。
- 3.4C実基板の版、USB TO UART入力条件、全負荷電流、表示/SD/Wi-Fi/照明の同時動作、電圧と温度を測定する。
- 文字盤追加・削除・切替、壊れたファイルからの復帰、RTC/SNTP、PSRAM使用量、30/60fpsを実機で受入する。
- eFuse EN LOW、既存安全ゲート、購買・製作・通電・フラッシュの保留を維持する。

設計資料の更新だけで実機の給電、表示性能、静音性、安全性を合格とはしない。
