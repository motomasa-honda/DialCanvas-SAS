# ADR-0010: 3.4Cメーカー公称値を機械CADの基準にする

- 日付: 2026-10-21
- 状態: **採用・現物取付受入前**
- 関連: [3.4C表示基板インターフェース](../docs/03-mechanical/display-board-interface.md)、[一台試作ベースライン](../docs/02-architecture/cots-prototype-baseline-2026-10-20.md)、[組立計画](../docs/08-manufacturing/assembly-plan.md)

## 背景

一台のみの試作に、寸法が公開されている既製表示基板を使う。実物が届くまで基本レイアウトを停止すると、公開仕様で判断できる画面・支持板・ケースの関係まで保留になり、設計が進まない。ユーザーは既製品の組み合わせを優先し、メーカーの公称値で進行する方針を明示した。

## 判断

1. Waveshare ESP32-P4-WIFI6-Touch-LCD-3.4C（SKU31523）のメーカー公称値、基板外形115×115mmと表示領域87.6×87.6mmを平面CADの設計値に採用する。
2. 後面支持板Bの開口120×120mmを維持する。基板を中央配置した際の公称通過すき間は各辺2.5mm。
3. 液晶ガラス面z=40mmを軸方向CADの基準面として採用する。保持キャリアの調整で面位置を合わせ、歯車支持板・軸座標の再変更は避ける。
4. 固定穴の実位置や背面部品高さが不確かなまま決め打ちしない。保持は独立した4点キャリアを基本とし、調整用長穴/シムを設ける。端子・microSD・USBへのアクセスを妨げない。
5. 公式公称値でケース・歯車・表示の配置設計を続ける。改版、取付穴、基板厚、端子、電流、熱、表示品質の現物照合は、最終キャリア・給電・動作を受け入れる段階で行う。

## 影響と境界

- サイズ候補を比較し直さず、外形・平面配置・ガラス面のCADを先へ進められる。
- 公称値にない穴位置、全厚、端子突出は未確定としてキャリア側へ調整性を持たせる。差異が大きく調整範囲を超えた場合のみ、その部品を直す。
- 本判断は機械エンベロープの設計基準であり、最終加工図の承認、購入、給電、ファームウェア書込み、製造ゲート完了を意味しない。
