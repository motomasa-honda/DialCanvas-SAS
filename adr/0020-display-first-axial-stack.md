# ADR-0020: 表示器を前に置く軸方向スタック

- 日付: 2026-10-22
- 状態: **一台用の机上配置候補。公開カタログ寸法を設計基準に採用**
- 関連: [設計ベースラインv0.21](../docs/10-desk-redesign/design-baseline-v0.21.md)、[BSS20候補](../docs/03-mechanical/bss20_axis_support_candidate-2026-10-22.md)、[表示基板インターフェース](../docs/03-mechanical/display-board-interface.md)、[ADR-0016](0016-waveshare-34c-mounting-and-clearance.md)

## 背景

現行のZ配置は、歯車面z=24…39mm、表示ガラスz=44.5mmで、表示器が歯車より後ろにあった。ユーザーが示した前後順「前から表示器→歯車」と一致しない。表示器と歯車を同じ奥行に置く案も、Ø115mm基板、支持板、歯車軸受けの干渉を避けられない。

型番・寸法は量産公差ではなく、公開カタログDrawing/STEPの値を一台用に使う。Waveshare SKU31523の個体リビジョン照合や独立試験片を購入条件にしない。

## 判断

1. 前ガード内面をz=0とし、表示ガラス前面をz=1.5mm、3.4Cの15.5mm保守包絡をz=1.5…17mmに置く。
2. 表示器の後ろに3mm PC四本腕キャリアz=19…22mmを配置する。公開図面のM4穴パターンを使い、±80mm位置のM3アンカーで前面支持板Aへ渡す。支持板A前面z=29mmとの間は合計7mmのスペーサ候補でつなぐ。
3. 支持板Aはz=29…37mm、中央開口Ø119mm、OILES座14か所と表示キャリアアンカー4か所を設ける。Ø115mmモジュールに対する公称半径方向すき間は2mm。支持板Bはz=70…78mm、中央120×120mm角開口とする。
4. 歯車Aのボス/歯面はz=38…46 / 46…52mm、歯車Bはz=61…69 / 55…61mmとする。A/B歯面間は3mm。A軸カラーはz=23…28mm、B側カラーはz=79…84mm。
5. 共通軸はz=26…91mm（6×65mm）。B側カラーがz=79…84mmを占めるため、NBK MJT-14-RD-4-6継手をz=84…106mmへ置く。モーター取付面z=108mm、本体後端z=141mmとし、継手との軸方向すき間2mmを取る。
6. 後壁内面z=148mmまでモーター後方7mmを保つ。前枠9mm + ガード3mm + 内部148mm + 背板12mmから、ケース外形の奥行候補を172mmとする。これは仮寸法で、背面電装/整備空間を統合後に確定する。
7. A支持板開口の近くにあるA11軸の支持ウェブを保つため、28位置の計算例ではA10→A11間の進行ベクトルだけを8°外側へ回す。A11以降はその位置ずれを平行移動して引き継ぎ、隣接歯車間距離20mmを維持する。歯車数28、座標、外寸270×205mmは要求として固定しない。

## 机上計算結果

`generate_bss20_axis_candidate.py`の検査結果は、最小ケース端余裕5.10mm、LCD有効円までの最小平面すき間12.19mm、支持ブッシュ穴と開口のウェブ3.49mm、POMワッシャーと開口のウェブ1.49mm、最小非隣接歯車すき間1.59mm、噛合中心距離誤差0.001mm未満。これらは公称2D包絡値で、実歯形、板たわみ、偏心、ケース材、線材を含む実機合格を意味しない。

## 影響

- ADR-0016のカタログ値（Ø115mm、穴ピッチ75×78.5mm、M4×4表記、15.50mm包絡）は維持する。同ADRの表示位置z=44.5mmと背面支持板Bへのキャリア案は本ADRで置き換える。
- ケース奥行は従来の145mm参照から172mmの配置候補へ増える。継手とB側カラーの重なりを避けるための5mm追加を含む。最終ケース図は配線、外装曲線と整備性を統合してから作る。
- カタログ品の型番/数量を選ぶための個体リビジョン照合、保持治具、圧入片、4歯車試験片は購入前の条件にしない。手回し、低速運転、線の接触/温度は完成品の組立受入で確認する。
- CADは寸法検討用で、購入・加工・製造リリースではない。
