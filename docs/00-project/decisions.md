# 現行設計判断

全構成・候補値・受入条件の統合正本は[設計ベースラインv0.21](../10-desk-redesign/design-baseline-v0.21.md)です。ここでは主要な判断のみを示します。

| 項目 | 現行判断 | 状態・根拠 |
| --- | --- | --- |
| 外観・外形 | 承認済み Forest Guardian の意匠、曲線ウォールナット外装を維持。外形270×205×145mmを参照寸法とする | 外観画像の高解像度原画/利用条件、最終寸法はFG-038/FG-006で未完 |
| 表示 | Waveshare ESP32-P4-WIFI6-Touch-LCD-3.4C SKU31523、円形800×800画面 | 部品改版、表示、電力、取付はPROVISIONAL/OPEN |
| 時刻/文字盤 | SNTP + DS3231 RTC候補、JST、microSDのJPEG/dial.json、ソフトウェアの連続3針 | 形式/ソース統合済み。表示・再起動・時刻復旧は実機未受入 |
| 歯車駆動 | 静音ステッパー1基で噛合い歯車群を連動。歯車数は固定しない | NEMA-8 #4411 / TMC2209 #6121 / 1.6rpm候補。トルク、音、熱は未受入 |
| 歯車配置 | 不規則二層配置。28個の候補CADを用いる | 個数は要求値ではない。実歯当たり、軸支持、負荷はFG-027で未完 |
| 電源 | PD 9V/3A → 9Vモーター枝 + #2851 5V枝。5VからTI TPS25810EVM sourceで表示器、LEDを分岐 | ADR-0014の暫定設計。全負荷と保護値はFG-048で未受入 |
| モーター安全 | モーター枝にヒューズ、VM直列の独立スイッチ、ENN pull-up、VM側TVS候補 | 旧M1 eFuseを含めない。リセット/故障/過電圧試験は未実施 |
| 筐体 | ウォールナットケース、透明PCガード/二層支持板、前後整備 | 名目寸法とスタックは設計ベースラインへ記録。加工図は実寸受入後 |

旧7軸設計資料は設計経緯の参照用として保持し、現行状態の根拠に使いません。
