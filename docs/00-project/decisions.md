# 現行設計判断

全構成・候補値・受入条件の統合正本は[設計ベースラインv0.21](../10-desk-redesign/design-baseline-v0.21.md)です。ここでは主要な判断のみを示します。

| 項目 | 現行判断 | 状態・根拠 |
| --- | --- | --- |
| 外観・外形 | 承認済み Forest Guardian の意匠、曲線ウォールナット外装を維持。外形270×205×167mmを配置参考候補とする | 前後スタックを収める暫定奥行。外観原本/利用条件、配線統合後の最終寸法はFG-038/FG-006で未完 |
| 表示 | Waveshare ESP32-P4-WIFI6-Touch-LCD-3.4C SKU31523、円形800×800画面。公開Drawing/STEP寸法を採用 | 個体リビジョン照合は購入条件にしない。画面→歯車の前後配置はADR-0020。取付・電力は実機組立後に受入 |
| 時刻/文字盤 | SNTP + DS3231 RTC候補、JST、microSDのJPEG/dial.json、ソフトウェアの連続3針 | 形式/ソース統合済み。表示・再起動・時刻復旧は実機未受入 |
| 歯車駆動 | 静音ステッパー1基で噛合い歯車群を連動。歯車数は固定しない | NEMA-8 #4411 / TMC2209 #6121 / 1.6rpm候補。トルク、音、熱は未受入 |
| 歯車配置 | 不規則二層配置。28個の候補CADを用いる | 個数は要求値ではない。実歯当たり、軸支持、負荷はFG-027で未完 |
| 電源 | Anker 511/HUSB238でPD 15V/2Aを要求。DFRobot DFR0758のUSB-A 5V出力からMPA-ACECSS03BKで表示器Type-Cへ給電。DFR1015でモーター用9V、Pololu #2851で補助5V | ADR-0019。カタログ型番は選定済み。実負荷・温度・ケーブル降下はFG-048で初号機受入。#4092特注とTPS25810専用基板は不要 |
| モーター安全 | モーター枝にヒューズ、VM直列の独立スイッチ、ENN pull-up、VM側TVS候補 | 旧M1 eFuseを含めない。リセット/故障/過電圧試験は未実施 |
| 筐体 | ウォールナットケース、透明PCガード/二層支持板、前後整備 | 270×205×167mmは暫定配置候補。外装/配線統合後の加工図は未完 |

旧7軸設計資料は設計経緯の参照用として保持し、現行状態の根拠に使いません。
