# 用語

- **現行設計**: 静かなモーター1基で装飾歯車群を連動させるForest Guardian / DialCanvas Desk Edition案。
- **候補**: 資料で比較・作図済みだが、実物・電気・機械の適合を受け入れていない構成。
- **文字盤**: microSD上の `face.jpg` と任意の `dial.json` で構成する表示単位。
- **装飾歯車**: 視覚表現用で、時計の時刻精度を担わない部品。
- **連続針**: システム時刻から小数秒まで反映し、段階的に跳ねずに描画する針。
- **実機受入**: 対象の基板・部品で条件と測定値を記録し、要求の合否を確認すること。ホスト試験やCADだけでは成立しない。
- **参照外形**: 270×205×145mm。最終外寸は実部品・配線・保護板を含めて確認する。
- **旧設計**: 7軸独立駆動など、要求移行表で旧案として識別した履歴。
