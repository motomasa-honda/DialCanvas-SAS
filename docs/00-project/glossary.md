# 用語

- **文字盤**: 時計の背景意匠、目盛り、針の動作設定を含む表示単位。データ形式は未決定。
- **装飾歯車**: 時刻精度を担わず、視覚表現のために回転する部品。
- **基準歯車**: 駆動設計で速度・経路の基準とする歯車。現時点では未選定。
- **承認済み外観 Version 1.0**: ユーザーが承認した外観。原本画像は現リポジトリに存在しない。
- **Phase 0**: 既存資産の保護、要求の整理、候補比較と試作計画の段階。
- **Phase 1**: 主要部品・構造候補を実測で絞り、試作設計に進む段階。

旧資料の用語集は [こちら](../requirements/DC-000/glossary.md) に保存する。
