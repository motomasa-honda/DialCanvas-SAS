# 製品ビジョン

Forest Guardian / DialCanvas Desk Edition は、ウォールナット筐体、円形の交換可能な電子文字盤、暖色の間接照明、連動して動く装飾歯車を備える一台限りの高級置き時計です。参照外形は270×205×145mm。最終寸法は実基板、取付、配線、保護板を照合して決めます。

時計針は画面上で時刻に追従して滑らかに動かし、装飾歯車の停止から独立させます。文字盤はmicroSDから差し替え、本体のロータリーエンコーダーで選びます。歯車は静かなモーター1基で連動させる設計案です。歯車の数は固定しません。

現時点の画面、モーター、ドライバー、歯車、電源、寸法は受入前の候補です。設計資料と実装状況は[現行基準](../10-desk-redesign/README.md)、要求状態は[要求台帳](../01-requirements/requirements.yaml)を参照してください。
