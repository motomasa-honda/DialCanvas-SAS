# 未決定事項

各行の要求 ID は [要求台帳](requirements.yaml) の `OPEN` と一対一で対応する。担当は現時点では設計者本人。判断には外観原本、候補部品の一次資料、実測結果が必要。

| ID | 関連要求 | 判断すべきこと | 判断に必要な証拠 |
| --- | --- | --- | --- |
| OQ-01 | FG-006 | 高さと内部クリアランス | 承認外観原本、画面・歯車・保護板の積層図 |
| OQ-02 | FG-009 | 前面保護板の素材・厚み・固定方法 | 反射、傷、加工、熱、整備性の比較 |
| OQ-03 | FG-016 | 文字盤データ形式・描画方式 | 複数文字盤の試作と表示性能 |
| OQ-04 | FG-020 | 表示器の解像度・IF・制御基板 | データシート、入手性、描画負荷、実機試験 |
| OQ-05 | FG-026 | 基準歯車と駆動経路 | 配置図、歯車回転方向、ベルト経路の試作 |
| OQ-06 | FG-027 | 必要トルク・逆回転・機構成立性 | 摩擦と負荷の実測、騒音・温度測定 |
| OQ-07 | FG-031 | LED の ON/OFF 操作 | 夜間使用評価、操作設計 |
| OQ-08 | FG-035 | 時刻同期と停電時バックアップ | 誤差許容・ネットワーク断・停電シナリオ |
| OQ-09 | FG-036 | ボタン配置、操作体系、Web 認証 | 操作シナリオと脅威・保守検討 |
| OQ-10 | FG-038 | 旧意匠と承認外観の原本・権利 | 元画像、製作者、利用条件の確認 |

決定後は要求状態を変更し、ADR と [変更履歴](change-history.md) を更新する。
