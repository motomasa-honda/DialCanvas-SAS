# Forest Guardian Phase 0 要求定義 v0.7

作成日: 2026-10-08。根拠: ユーザー提示の「Forest Guardian / DialCanvas Desk Edition」Phase 0 v0.7 と追加ディレクトリ指示。要求 ID・状態・検証 ID の原本は [要求台帳](requirements.yaml)。本書は人が読むためのベースラインであり、候補部品や実現性の承認ではない。

状態: `FIXED` は現時点の確定、`PROVISIONAL` は暫定目標、`OPEN` は未決定、`REJECTED` は明示的に採用しない案、`SUPERSEDED` は後続要求で置換された履歴。状態変更には [変更履歴](change-history.md) を追加する。

## 製品・外観

名称は Forest Guardian / DialCanvas Desk Edition。個人製作の高級置き時計で、品質を優先し予算は柔軟に調整する。ユーザー承認済み外観 Version 1.0 を維持し、曲線ウォールナットフレームとキャビネット構造を融合する。承認画像の原本は本リポジトリにないため、外観の幾何形状をここで再定義しない。幅 25〜35 cm、奥行 10〜15 cm は暫定範囲。高さは未決定。無垢材と突板を部位別に使い、前後から整備可能にする。前面全体を透明保護板で覆う。保護板の素材は未決定。

## 文字盤・表示

既存 Forest Guardian 意匠の指定は、12 時の鳥居、中央のケモミミシルエット、9 時の三日月、3 時の花・髪飾り、6 時の肉球、橙色の尻尾をモチーフにした秒針、背面刻印 `THE GUARDIAN OF THE FOREST`。中央シルエットを最重要とする。元画像や権利情報は未収集。

中央に円形電子ディスプレイを置き、時計針はソフトウェアで描画する。文字盤は追加・削除・切り替え可能にし、デフォルト文字盤は削除不可、選択状態は再起動後も保持する。針の動作方式は文字盤ごとに設定可能。データ形式、描画エンジン、保存方式は未決定。

画質、黒の美しさ、発色を最優先にし、昼夜とも快適に読めることを目指す。タッチ操作は不要。2.8 型・3.4 型などの円形 OLED と IPS 液晶を比較し、OLED の焼き付き・寿命を評価する。解像度、接続方式、制御基板は未決定。[比較の評価軸](../05-display/comparison-plan.md) を先に固定する。

## 装飾歯車・照明

歯車は 5〜7 枚を文字盤の周囲に配置し、アンティークブラス仕上げを目指す。金属と樹脂を適材適所で使用する。電動でゆっくり回転させ、時計回りと反時計回りを混在させる。目標回転周期は 1 回転 10〜60 秒。基準歯車は未決定。通常は常時回転し、ユーザーが ON/OFF を操作できる。速度のユーザー調整は要求しない。わずかな動作音は許容する。

歯車同士の噛み合いは必須ではない。背面ベルト駆動・モーター 1 個を第一候補とするが、逆回転、ベルト経路、トルク、軸受、干渉、実際の成立性は未検証。[機構検証計画](../03-mechanical/gear-feasibility.md) に判断基準を置く。

暖色 LED で一定の間接照明を行い、光源が直接目立たない構成を優先する。点滅や派手な演出は採用しない。ユーザーによる LED ON/OFF は未決定。

## 操作・システム

本体物理ボタンと Wi-Fi 経由の Web 管理を設ける。Web から文字盤の追加・削除・切り替えを行う。時計と歯車の制御は分離する。時刻同期と停電時のバックアップ方式、ボタン配置・操作体系、認証・更新方式は未決定。安全性と保守性の検証なしに実装選択を確定しない。

## Phase 0 の成果境界

この版では要求、未決定事項、リスク、評価順序、検証計画を定義する。CAD、回路図、BOM、製品ファームウェア、Web UI の完成は対象外。Phase 1 に進む条件は [移行条件](../09-verification/phase1-gate.md) を参照する。
