# 技術的リスク一覧

| ID | リスクと影響 | 現時点の評価 | 低減・確認方法 | 関連要求 |
| --- | --- | --- | --- | --- |
| R-01 | 円形 OLED の焼き付き・寿命、昼夜視認性が期待未満 | 高 | 同一描画条件の長時間試験、輝度・温度・視認性比較 | FG-017〜FG-020 |
| R-02 | 表示器と制御基板の IF、メモリ、更新速度が不適合 | 高 | 一次資料照合と最小描画試作 | FG-020 |
| R-03 | 背面ベルトで逆回転・配置・トルク・騒音が成立しない | 高 | 回転方向図と試作治具で測定 | FG-023〜FG-027 |
| R-04 | 木材変形・温湿度変化・保護板の反射が意匠と整備性を損なう | 中 | 材料試験、前後アクセス模型、光学評価 | FG-007〜FG-009 |
| R-05 | 電源、モーター、LED のノイズ・発熱が時計表示に影響 | 中 | 電源系分離案、電流・温度・ノイズ実測 | FG-030, FG-034 |
| R-06 | 電源断や通信断で時刻・選択文字盤・設定が失われる | 中 | 停電・再起動・Wi-Fi 断シナリオ試験 | FG-015, FG-035 |
| R-07 | Web 管理の無認証操作や不正ファイル取り込み | 中 | 認証・入力検証・更新経路の設計レビュー | FG-033, FG-036 |
| R-08 | 外観・文字盤の承認原本と権利情報が不在 | 高 | 原本と出典を収集し、再現前に利用条件を確認 | FG-010, FG-038 |

評価は Phase 0 の定性的な優先度であり、故障率や実測値ではない。
