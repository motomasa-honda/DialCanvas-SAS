# 新設計のシステム境界

時計表示、文字盤入力、時刻管理、装飾歯車、照明、電源を別の責務として扱います。装飾歯車は時計の時刻計測に使いません。

| 機能 | 入力 | 責務 | 現在の証拠・未完了 |
| --- | --- | --- | --- |
| 時刻管理 | SNTP、外付けDS3231候補 | UTC復旧、同期、ローカル時刻変換 | C変換とアプリ処理は実装。RTC/ネット断の実機試験が未完 |
| 文字盤 | microSDのJPEGと任意dial.json | 一覧、描画、選択、永続化 | ソースとCコア試験あり。基板上の表示/SDは未試験 |
| 時計表示 | システム時刻、文字盤画像 | 滑らかな3本針描画 | 16ms LVGL更新要求。フレーム安定性は実機未測定 |
| 歯車駆動 | 利用者の明示操作、電源状態 | 単一モーターで歯車群を連動 | GPIO出力は既定無効。ドライバーと機構は候補 |
| 照明 | 独立物理スイッチ | 暖色間接LEDを一定点灯 | LEDと安全な枝回路は未選定 |
| 電源 | USB-C入力、表示・モーター・LED負荷 | 保護、枝分け、電流と熱管理 | PD/9V/5V候補図のみ。全負荷評価は未実施 |

モーターを停止しても時計表示と時刻同期を継続します。物理遮断スイッチと電気的保護はソフトウェアだけに依存させません。候補GPIOの確定前は実機出力を有効にしません。
