# システム境界の暫定整理

時計表示、歯車駆動、照明、入力、Web 管理、時刻保持を別の機能領域として扱う。これは責務の分離であり、制御基板を何枚使うかの決定ではない。

| 領域 | 入力 | 出力・責務 | 未決定事項 |
| --- | --- | --- | --- |
| 時刻保持 | 時刻同期源、バックアップ源 | 時計表示へ時刻を提供 | RTC、同期周期、停電時保持 |
| 文字盤描画 | 時刻、選択文字盤、針設定 | 円形画面の画像と針 | 表示器、描画形式、フレーム更新 |
| 歯車制御 | 運転 ON/OFF、電源状態 | モーター駆動 | モーター、ドライバ、速度固定値 |
| 照明制御 | 電源状態、必要なら操作 | 暖色 LED の一定点灯 | 調光と ON/OFF の要否 |
| 操作管理 | 物理ボタン、Web 要求 | 文字盤・歯車の状態変更 | 操作優先順位、認証、競合処理 |
| 設定保存 | 選択文字盤などの変更 | 再起動後の状態復元 | 記憶媒体、書込耐久、障害復旧 |

歯車が停止または故障しても時計表示を維持できるよう、制御状態と故障処理を分ける。電源系の実際の絶縁・分割は [電気設計メモ](../04-electronics/power-and-control.md) で検証する。
