## 回答の判定ルール

| 受領した情報 | 設計上の扱い |
|---|---|
| 型番・改版・寸法を明記したメーカー/販売元の書面 | CAD/BOMの前提を更新。回答対象と対象ロットを記録 |
| 価格・納期だけの見積 | 費用/日程のみ更新。仕様適合はOPENのまま |
| 「同等品」「現行品」など型番/改版がない回答 | 現行SKUと結び付けられないためOPENのまま |
| 回答なし/公表なし | 推測で埋めず、現物受入または別候補比較へ回す |
| 材料/試験片/計器の見積 | 段階評価パッケージの費用表へ反映。発注許可とは別 |

全ての回答と見積を反映した後に、同じ設計改版の試験用BOM・加工図・受入票を作成します。現物試験を含む必要部材が揃って初めて、評価用の少数注文を提示します。完成機の全量BOMは、評価試験PASSと電装/筐体統合が済むまで分けて保留します。
