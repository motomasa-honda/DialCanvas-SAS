更新日：2026-10-22

状態：**Waveshare公開2D/3D資料を読み取り、机上配置値を更新済み。SKU31523現物の改版照合、固定具、抜差し・配線包絡は未受入。**

## 設計に使う公称値

Waveshare ESP32-P4-WIFI6-Touch-LCD-3.4C（SKU 31523）の公式Drawing ZIPを2026-10-22に取得し、PDF/DXF/STEPを確認した。前面外形は円形Ø115.00mmで、`115×115mm`は円形モジュールの最大矩形包絡である。PDFはガラス厚6.00mm、全厚15.10mmを示し、公式STEPの全体包絡は115×115×15.50mmでPDFより0.40mm深い。机上包絡モデルでは15.50mmを使う。

取付図の外周4点は`4-M4×4.00`表記で、図面解釈は**M4タップ穴・ねじ深さ4.00mm**。中心は基板中央からX=±37.50mm、Y=±39.25mm、ピッチ75.00×78.50mmである。前回の「75×75mm」は内部基板固定ねじ列と混同した誤読なので撤回する。公開参照回路図は設計rev1.1を示すが、購入個体のPCB版/穴仕様は保証しない。現物の改版、ねじ掛かり、コネクター、抜差し空間は受領時に照合する。

| 基準 | 寸法 | この設計での使い方 |
|---|---:|---|
| 前面パネル外形 | Ø115.00mm | 115×115mmの保守的な最大矩形包絡で支持板開口との干渉を確認 |
| ガラス外径 | Ø112.50mm +0.10mm | 透明支持板の開口/遮蔽と外観を照合 |
| レンズ視野 | Ø88.20mm ±0.20mm | 視認開口と文字盤の配置確認 |
| LCD有効領域 | Ø87.60mm | 800×800有効画面の直径 |
| ガラス厚 | 6.00mm | 外装前面からモジュール内部への段差確認 |
| 全厚 | PDF 15.10mm / STEP包絡15.50mm | 差0.40mm。机上モデルは15.50mmを使用し、現物受入で確定 |
| 外周取付穴 | 図面表記`4-M4×4.00` | M4タップ・深さ4.00mmと解釈。個体受入で照合 |
| 外周取付穴ピッチ | X=±37.50mm、Y=±39.25mm | 中心間75.00×78.50mm。内部PCBねじ位置とは別 |
| 後面支持板の開口 | 120×120mm | 円形前面パネルと後部基板・端子を通すための候補開口 |
| 基板包絡と開口の差 | 最大矩形115mmに対して5mm | 中央配置で公称2.5mm/辺。固定穴が開口範囲内にあるため独立保持キャリアが必要 |
| 画面ガラス面 | z=44.50mm候補 | B歯面終端z=39mmから5.50mmの名目軸方向すき間 |
| 基板奥行包絡 | z=44.50…60.00mm | STEP最大深さ15.50mm。後面支持板z=48…56mmの120mm角開口を通す候補 |

120mm角開口は円形Ø115mmモジュールの最大矩形包絡より5mm大きい。外周M4穴は開口の中にあり、支持板Bへ直接ねじ止めできないため、開口外側の支持板へ荷重を渡す保持キャリアが必要となる。取付穴はタップ深さ4.00mmと読み取れるが、ねじ長と頭部/背面部品との離隔が閉じるまではねじを購入しない。保持キャリアは4穴パターン、コネクター、microSD/USB抜差し包絡を含む図面にしてから確定する。

## 寸法の算術確認

- 後面開口の通過すき間：`(120 − 115) / 2 = 2.5mm/辺`。
- 前面開口と表示領域の半径方向差：`(112 − 87.6) / 2 = 12.2mm`。
- ケース内面246×181mmへ最大矩形包絡を中央配置したときの余白：左右各65.5mm、上下各33mm。
- ガラス前面z=44.50mm候補、15.50mm奥行包絡はz=44.50…60.00mm。後面支持板z=48…56mmの中央120mm角開口を通す。
- B歯面終端z=39mmとの軸方向名目すき間は5.50mm。図面寸法からのCAD値で、振れ/板たわみ/保持具を含む受入値ではない。

机上設計で閉じた値は、外径/表示径、外周M4穴の75×78.5mmパターン、図面解釈上の4mmねじ深さ、15.50mmの保守的な深さ包絡である。表示面をz=44.50mmへ移し、B歯面との名目軸方向すき間を1.00mmから5.50mmへ増やした。基板版、穴仕様、各コネクターの突出し/向き、USB/microSDの挿抜空間、ケーブル曲げ、電流、保持キャリアと振れ/たわみ込みすき間は未受入であり、現物と保持具を重ねるまで加工寸法を出さない。

## 設計と実物受入の分離

1. **机上配置**：公式図面の円形外形、ガラス、外周M4穴パターンに合わせる。包絡モデルには15.50mm深さを使い、ガラス面はz=44.50mm候補とする。
2. **部品表/取付図を発行する前**：同一SKUの現物または販売元の現行改版情報で、M4ねじ深さ、端子位置/高さ、microSD/USBの挿抜を照合する。保持キャリア・ねじ長・ケーブル経路を同じ3D座標へ反映し、歯車/ガラスの最小すき間を公差込みで確認する。
3. **現物を組み付ける時**：基板改版、ガラス/全厚、外周M4穴と実ねじ掛かり、ねじ頭、コネクター、microSD/USBの抜差し、画面面位置を記録する。CAD/図面と不一致があれば、支持板・保持キャリア・歯車座標を量産/全量購入前に修正する。

この文書は一台用の設計基準であり、加工承認、発注承認、通電許可を意味しない。
