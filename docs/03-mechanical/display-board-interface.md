# 3.4C表示基板の寸法インターフェース

更新日：2026-10-22

状態：**Waveshare公開2D/3D資料を読み取り、机上配置値を更新済み。SKU31523現物の改版照合、固定具、抜差し・配線包絡は未受入。**

## 設計に使う公称値

Waveshare ESP32-P4-WIFI6-Touch-LCD-3.4C（SKU 31523）の公式Drawing ZIPを2026-10-22に取得し、PDF/DXF/STEPを確認した。前面外形は円形Ø115.00mmで、`115×115mm`は円形モジュールの最大矩形包絡である。PDFはガラス厚6.00mm、全厚15.10mmを示し、公式STEPの全体包絡は115×115×15.50mmでPDFより0.40mm深い。机上包絡モデルでは15.50mmを使う。

取付図の外周4点は`4-M4×4.00`表記で、図面解釈は**M4タップ穴・ねじ深さ4.00mm**。中心は基板中央からX=±37.50mm、Y=±39.25mm、ピッチ75.00×78.50mmである。前回の「75×75mm」は内部基板固定ねじ列と混同した誤読なので撤回する。公開参照回路図は設計rev1.1を示すが、購入個体のPCB版/穴仕様は保証しない。現物の改版、ねじ掛かり、コネクター、抜差し空間は受領時に照合する。

| 基準 | 寸法 | この設計での使い方 |
|---|---:|---|
| 前面パネル外形 | Ø115.00mm | 115×115mmの保守的な最大矩形包絡で支持板開口との干渉を確認 |
| ガラス外径 | Ø112.50mm +0.10mm | 透明支持板の開口/遮蔽と外観を照合 |
| レンズ視野 | Ø88.20mm ±0.20mm | 視認開口と文字盤の配置確認 |
| LCD有効領域 | Ø87.60mm | 800×800有効画面の直径 |
| ガラス厚 | 6.00mm | 外装前面からモジュール内部への段差確認 |
| 全厚 | PDF 15.10mm / STEP包絡15.50mm | 差0.40mm。机上モデルは15.50mmを使用し、現物受入で確定 |
| 外周取付穴 | 図面表記`4-M4×4.00` | M4タップ・深さ4.00mmと解釈。個体受入で照合 |
| 外周取付穴ピッチ | X=±37.50mm、Y=±39.25mm | 中心間75.00×78.50mm。内部PCBねじ位置とは別 |
| 後面支持板の開口 | 120×120mm | 円形前面パネルと後部基板・端子を通すための候補開口 |
| 基板包絡と開口の差 | 最大矩形115mmに対して5mm | 中央配置で公称2.5mm/辺。固定穴が開口範囲内にあるため独立保持キャリアが必要 |
| 画面ガラス面 | z=44.50mm候補 | B歯面終端z=39mmから5.50mmの名目軸方向すき間 |
| 基板奥行包絡 | z=44.50…60.00mm | STEP最大深さ15.50mm。後面支持板z=48…56mmの120mm角開口を通す候補 |

120mm角開口は円形Ø115mmモジュールの最大矩形包絡より5mm大きい。外周M4穴は開口内にあるため、開口外側の支持板Bへ荷重を渡すキャリアを設ける。図面値から下記の4本腕キャリア候補をCADに追加した。現物の穴仕様、背面部品/端子との干渉、保持板のたわみはまだ受入前なので、穴あけや切出しの指示ではない。

## 取付キャリア候補 v0

キャリアは、選定済みの透明PC評価材 KPAC303-1（厚さ3mm）から作る一体の4本腕部品とする。支持板Bを穴あけせず開口に載せる方式ではなく、板Bの開口外4隅へM3貫通ボルトで固定し、基板の外周M4穴で表示器を吊る。現行CADの候補形状は[包絡モデル](bss20_clock_envelope_review.scad)と[配置図](display_carrier_candidate.svg)に反映した。

| 部位 | 候補仕様 | 図面上の理由/状態 |
|---|---|---|
| 材料 | 透明PC 3mm、KPAC303-1の余材候補 | 製品ガード用に選定済みの評価材と同じ。ガードを270×205mmで取る場合でも190×190mmのキャリア素材は300×450mm板に収まる机上配置。実輪郭/切りしろはまだ未確定 |
| 基板側腕 | 4本、幅18mm、M4クリアランス穴Ø4.5mm。中心X=±37.50、Y=±39.25mm | 公式穴パターンから算出。4mmタップ深さの図面解釈を現物照合する |
| 支持板側アンカー | X/Y=±80mm、穴Ø3.4mm。腕の外形は中心±89mm以内 | 120mm開口の外側に配置。190mm角素材に6mmの縁余白を残す。支持板B短辺端から最小4.5mmの外形余白 |
| 支持板側スタンドオフ | 4個、長さ6mm、外径6mm・M3通し穴相当 | 支持板Bの上面z=56mmからキャリア下面z=62mmまで。支持板Bは8mm厚PCで、M3貫通ボルト、平座金、ゆるみ止めナットで挟む候補 |
| 基板側スペーサ | 4個、厚さ2mm、M4用絶縁スペーサ候補 | 基板後面の公称最大z=60mmとキャリア下面z=62mmの間。穴周囲に平らな座面があることを現物で確認 |
| 基板締結 | M4×8mm pan-head候補 | 3mmキャリア+2mmスペーサ後の公称ねじ掛かり3mm、図面解釈上の4mm穴深さに1mm余裕。頭部形状、実ねじ、底付きは個体で確認 |
| 支持板締結 | M3×25mm貫通ねじ4本、平座金/ゆるみ止めナット | 8mm支持板+6mmスタンドオフ+3mmキャリアの積層を通す。近接歯車軸B04まで16.42mm。上側のØ6mm脚とØ12mm歯車ワッシャー間は7.42mm、支持板裏のØ9mm座金と歯車ワッシャー間は同一面で約5.92mmの公称余裕 |

18mm腕は各M4座から斜め外側の開口角へ伸び、基板中央は覆わない。腕は基板包絡の最大深さz=60mmから2mm離れたz=62mmに置く。公開STEP包絡が入手個体にも当てはまる場合の机上すき間であり、四隅側の端子/コネクターや挿抜・ケーブル経路、基板改版への適合保証ではない。組立前に4穴座面へ2mmスペーサが平らに載ること、全ポートが使えること、組立後に画面ガラスとB歯車が擦れないことを確認する。

この案でCAD上の保持方式と支持点は具体化したが、実物受入と同一材のたわみ確認が済んでいないため、キャリア材やねじを完成機BOMへ昇格させない。現物と合わない場合は、M4座のスペーサ厚、腕幅、M3アンカー位置を変更可能なキャリアだけを作り直す。支持板Bの歯車穴/軸位置は変更しない。

## キャリア締結具の寸法候補

以下の規格寸法で一式にします。ねじ長さはスタックから算出済みですが、表示基板のM4ねじ深さ解釈、取付座面、キャリアたわみを現物確認するまで購入指示/製作指示ではありません。

| 用途 | 選定寸法 | 数量 | 寸法の根拠 |
|---|---|---:|---|
| 基板M4ねじ | SUS304/A2、M4×8mm、なべ頭・十字穴（JIS B 1111相当） | 4 | PCキャリア3mm + 絶縁スペーサ2mm = 5mm。基板側へ3mm掛かり、図面解釈上の深さ4mmに1mm余裕 |
| 基板側絶縁スペーサ | POM、ID4.3×OD8×長さ2mm | 4 | M4軸周囲を絶縁し、公開STEPの基板背面包絡とキャリア下面を2mm離す |
| 支持板側通しねじ | SUS304/A2、M3×25mm、なべ頭・十字穴（JIS B 1111相当） | 4 | 8mm支持板B + 6mmスペーサ + 3mmキャリア = 17mm。大型座金とナイロンナット込みでも締結可能 |
| 支持板側スペーサ | POM、ID3.2×OD6×長さ6mm | 4 | 支持板B上面z=56mmからキャリア下面z=62mmまで |
| 平座金 | SUS304/A2、M3用、ID3.2×OD9×厚0.8mm（DIN 9021相当） | 8 | 支持板B裏面とキャリア上面を両側から広く押さえる。18mm腕幅に収まる |
| ゆるみ止めナット | SUS304/A2、M3ナイロンインサート六角ナット（DIN 985相当） | 4 | キャリア上面側の通しねじを緩みにくくする |

M4基板ねじはキャリアに座る頭部で押さえるため、別座金を追加しません。追加すると有効掛かりを減らすため、別部品へ置換しないでください。M3×25mmは頭下長さです。手締めでPCへ過大な圧力を掛けないようにし、規格/メーカーから指定のない締付トルクは作りません。M4ねじ底付き、実ねじ掛かり、M3座金の端余裕、キャリアたわみはD2-1で確認します。

## 寸法の算術確認

- 後面開口の通過すき間：`(120 − 115) / 2 = 2.5mm/辺`。
- 前面開口と表示領域の半径方向差：`(112 − 87.6) / 2 = 12.2mm`。
- ケース内面246×181mmへ最大矩形包絡を中央配置したときの余白：左右各65.5mm、上下各33mm。
- ガラス前面z=44.50mm候補、15.50mm奥行包絡はz=44.50…60.00mm。後面支持板z=48…56mmの中央120mm角開口を通す。
- B歯面終端z=39mmとの軸方向名目すき間は5.50mm。図面寸法からのCAD値で、振れ/板たわみ/保持具を含む受入値ではない。

机上設計で閉じた値は、外径/表示径、外周M4穴の75×78.5mmパターン、図面解釈上の4mmねじ深さ、15.50mmの保守的な深さ包絡、およびキャリアの4穴接続方式/候補寸法である。表示面をz=44.50mmへ移し、B歯面との名目軸方向すき間を1.00mmから5.50mmへ増やした。基板版、穴仕様、M4座面の形、各コネクターの突出し/向き、USB/microSDの挿抜空間、ケーブル曲げ、保持キャリアのたわみと振れ込みすき間は未受入であり、現物と保持具を重ねるまで加工寸法を出さない。

## 設計と実物受入の分離

1. **机上配置**：公式図面の円形外形、ガラス、外周M4穴パターンに合わせる。包絡モデルには15.50mm深さを使い、ガラス面はz=44.50mm候補とする。
2. **部品表/取付図を発行する前**：同一SKUの現物または販売元の現行改版情報で、M4ねじ深さ、端子位置/高さ、microSD/USBの挿抜を照合する。保持キャリア・ねじ長・ケーブル経路を同じ3D座標へ反映し、歯車/ガラスの最小すき間を公差込みで確認する。
3. **現物を組み付ける時**：基板改版、ガラス/全厚、外周M4穴と実ねじ掛かり、ねじ頭、コネクター、microSD/USBの抜差し、画面面位置を記録する。CAD/図面と不一致があれば、支持板・保持キャリア・歯車座標を量産/全量購入前に修正する。

この文書は一台用の設計基準であり、加工承認、発注承認、通電許可を意味しない。
