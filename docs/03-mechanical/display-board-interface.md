# 3.4C表示基板の公称寸法インターフェース

更新日：2026-10-21

状態：**メーカー公称寸法を使ったCAD基準。最終取付・加工の受入前。**

## 設計に使う公称値

Waveshare ESP32-P4-WIFI6-Touch-LCD-3.4C（SKU 31523）のメーカー掲載値を、初号機の機械レイアウト基準として使う。製品寸法は115×115mm、表示領域は87.6×87.6mm。画面サイズや基板外形を選び直すため、現物を待つ必要はない。

| 基準 | 寸法 | この設計での使い方 |
|---|---:|---|
| 表示基板の外形 | 115×115mm | 後面開口の中央に置く公称エンベロープ |
| 表示領域 | 87.6×87.6mm | 円形ガラス/有効表示領域の最大投影として照合 |
| 後面支持板の開口 | 120×120mm | 現行支持板Bの開口を維持 |
| 基板外形と開口の差 | 5mm | 中央配置で公称2.5mm/辺の通過すき間 |
| 前面支持板の開口 | Ø112mm | 表示領域外周に公称12.2mmの半径方向余裕 |
| 画面ガラス面 | z=40mm | 軸方向CADの基準面。固定金具の調整でこの面へ合わせる |

開口は115mm角の基板エンベロープより5mm大きいため、基板を120mm角開口の内壁だけで保持しない。支持板Bの背面側に独立した保持キャリアを設け、基板端の部品・端子・カードの抜差し空間を避けて4点で支える。キャリアの長穴とシムで位置を調整できる構造にし、寸法図にない固定穴位置や背面部品高さを決め打ちしない。

## 寸法の算術確認

- 後面開口の通過すき間：`(120 − 115) / 2 = 2.5mm/辺`。
- 前面開口と表示領域の半径方向差：`(112 − 87.6) / 2 = 12.2mm`。
- ケース内面246×181mmへ中央配置したときの基板周囲余白：左右各65.5mm、上下各33mm。
- 液晶面z=40mmは後面支持板z=36…44mmの中に置く。歯車配置・軸方向図の前提として固定する。

この確認で閉じるのは、平面外形と名目の表示面位置だけ。基板全厚、背面コネクターの突出、カード/USBの抜差し包絡、改版差は別の最終受入項目で、現行の全体配置や他部品選定を止めない。

## 設計と実物受入の分離

1. **いまの設計**：製品ページと公式寸法図の公称値で、ケース、歯車支持板、表示開口、115mm角基板の配置を進める。
2. **加工図を閉じる前**：同じSKUの公式寸法図に従って基板固定穴と背面端子のキープアウトを反映する。保持キャリアは調整余裕を残す。
3. **現物を組み付ける時**：基板改版、固定穴、板厚、ねじ長、コネクター、microSD/USBの抜差し、画面面の位置を確認する。公称値との差はキャリアの長穴/シムで吸収し、支持板や歯車座標は動かさない。

この文書は一台用の設計基準であり、加工承認、発注承認、通電許可を意味しない。
