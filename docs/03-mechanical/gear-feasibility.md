# 単一モーター歯車列の成立性

## 現行候補

静かなモーター1基で不規則な複数歯車を連動させます。歯車数は固定しません。最新の配置検討は[ADR-0007](../../adr/0007-asymmetric-28-gear-layout.md)と[ADR-0012](../../adr/0012-cost-first-guard-and-gear-baseline.md)に記録し、28個はCAD候補の数であって要求値ではありません。

公開寸法に基づく平面図、二層断面、軸表、支持板図、4歯車の手回し試験手順を置いています。公称2D寸法は歯当たり、部品公差、軸振れ、支持板変形、配線、実負荷を含まないため、加工図や合格証拠ではありません。

## 未検証の項目

1. 選定した歯車の現物と軸・ブッシュの嵌合、保持、摩擦。
2. 二層の全噛合い、逆回転、軸方向干渉、表示基板・配線との隙間。
3. モーターとドライバーの電流、速度設定、必要トルク、始動余力、脱調。
4. 実際の騒音、連続運転温度、停止・再始動、手動遮断。

無通電の手回し確認から始める手順は[4歯車試験](four-gear-manual-test.md)を参照します。購入・加工・通電はこの計画から許可されません。未完了条件はDR-04に集約します。
