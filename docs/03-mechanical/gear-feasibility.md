# 装飾歯車の成立性検証計画

## 現行A案（2026-10-19）

7軸独立駆動A案を現行設計とする。故障時に対象1軸の市販ドライバーモジュールを交換でき、歯車・P3主要構造・他6軸を外さない構造を維持する。電装は市販ギヤードステッパーと市販ドライバーボードの組合せを優先し、装飾円板、ハブ、共通カセット、取付アダプターに専用形状を限る。[既製品優先の全体監査](../02-architecture/module-first-audit-2026-10-19.md)、[ADR-0004](../../adr/0004-module-first-system-review.md)、[G4-04既製品比較](../../execution/g4_04_cots_motor_pairing_2026-10-19.md)。

単一モーター＋背面ベルト案は初期候補の履歴であり、現行A案ではない。現行A案で次を閉じる。

1. 承認済み外観と選定表示器の実寸から、7軸位置・回転方向・保護板距離を確定する。
2. 市販モーター、軸、ハブ、軸受を実寸で照合し、歯車との結合アダプターだけを設計する。
3. 各軸の歯車質量、慣性、軸受摩擦を見積もり、10〜60秒/回転（1〜6rpm）の運転範囲で始動トルク、脱調、騒音、温度、振動を評価する。
4. モータードライバー1枚を歯車・P3・他軸を外さず交換する手順と、55mmのサービス動作包絡をCAD・工具形状・配線込みで確認する。
5. 装飾歯車のON/OFFと時計表示の独立性を維持し、歯車の運転精度を時刻精度の基準にしない。

「わずかな動作音」は許容されるが、数値上限は未設定。音の測定距離と許容基準、温度条件は連続運転受入れ前に定義する。CAD上のクリアランスだけでは現物の交換性、強度、騒音、温度を完了扱いにしない。
