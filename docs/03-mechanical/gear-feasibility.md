# 装飾歯車の成立性検証計画

背面ベルト・単一モーターは第一候補であり、成立は未確認。5〜7 枚の配置と外観を前提に、以下の順で検証する。

1. 承認外観と選定表示器の実寸から、軸位置・回転方向・保護板との距離を描く。
2. 単純ベルト、交差ベルト、中間軸/アイドラを比較し、要求される正逆回転とベルトの干渉回避を図示する。基準歯車を選ぶ。
3. 各軸の質量、慣性、軸受摩擦、ベルト張力を見積もり、試作治具で始動トルク・定常電流・滑りを測る。
4. 10〜60 秒/回転の範囲、起動停止、連続運転時の音・温度・振動、歯車 ON/OFF と時計表示の独立性を確認する。
5. ベルト交換と前後アクセスを模型で試し、成立しない場合は複数モーターなどを新 ADR で評価する。

「わずかな動作音」は許容されるが、数値の上限は未設定。試作前に測定距離と許容基準を決める。時計の精度は装飾歯車の回転精度に依存させない。
