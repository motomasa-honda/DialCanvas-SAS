# 単一モーター歯車列の成立性

## 現在の機械候補

静音モーター1基で装飾歯車列を動かします。7軸固定でも歯車数固定でもありません。現行mainの28位置は配置計算例です。

直近の機械候補は[KHK BSS1-20C・6mm軸支持案](bss20_axis_support_candidate-2026-10-22.md)です。型番を1つに揃え、6mm h7ピン、OILES 80B-0608、KSC0605、POMワッシャーを同じZスタックへ記載しました。全28位置の公称2D計算で最小ケース内余裕5.10mm、LCD有効円Ø87.6mmへの最小平面すき間9.40mm、支持ウェブ4.00mm、ワッシャーと開口のウェブ2.00mm、非隣接歯車間すき間1.59mmです。9.40mmは表示有効円への距離で、ガラス/モジュール外径の余裕とは異なります。公式Drawing外径Ø115mmと重なる位置があるため、表示ガラス面をz=44.50mm候補へ移し、B歯面終端z=39mmからの名目軸方向すき間を5.50mmとしました。実歯形、部品公差、軸振れ、板たわみ、配線、実負荷は未検証です。

再現用の[生成スクリプト](generate_bss20_axis_candidate.py)、[28位置/Z座標CSV](gear_axis_schedule_bss20_candidate.csv)、[配置SVG](irregular_layered_gear_layout_bss20_candidate.svg)、[A/B支持板穴配置SVG](gear_support_plate_A_bss20_candidate.svg) / [B](gear_support_plate_B_bss20_candidate.svg)、[筐体/表示/モーター包絡SCAD](bss20_clock_envelope_review.scad)を置いています。配置SVG/SCADは寸法図ではなくCAM出力でもありません。

## 購入と受入の停止点

- BSS1-20CのM4止めねじが6mmピン上で滑らないか未試験です。KHKは止めねじを簡易固定と案内し、確実な固定にキー/ノックピン併用を示しています。[試験票](four-gear-manual-test.md)の95〜105g重りを73〜77mmレバーへ掛ける両方向約0.070N·m静的保持試験をPASSするまで、全量購入を保留します。歯車側は試験台に固定し、軸側へレバーを付けます。校正済みトルク計は不要です。
- OILES 80B-0608の圧入後内径は、指定リングゲージへ圧入後の寸法です。軸h7、ハウジングH7が仕様候補ですが、透明PC板の割れ/白化と適合が未確認です。同材試験片で圧入力、内径、割れ、軸回転を確認するまで支持板の材料購入/加工を保留します。
- 駆動に使う継手と共通軸、モーター実寸、表示基板保持キャリアと背面配線の三次元適合はまだ確認していません。
- 表示ガラスとB歯面のCAD名目軸方向すき間は5.50mm、モーター後壁の名目すき間は7mmです。表示器は後面支持板の120mm角開口を通り、公式M4取付穴も開口内にあるため、保持キャリアをモデル化する必要があります。正確な基板改版、ねじ深さ、部品振れ、支持板/ケース公差を含む実物確認まで筐体/支持板/表示部の全量購入を保留します。
- 4歯車の無通電試験は[試験票](four-gear-manual-test.md)を使います。PASSしても全28位置、モーターの始動/停止、音、振動、温度は未受入です。

よって現在の状態は「候補を型番・数量・公称スタックまで具体化した」段階であり、全量購入/組立リリースではありません。現物・加工・通電・書込みは本書から許可されません。未完了条件はDR-04/DR-06に集約します。

## 旧機械案の保留根拠

[購入前設計監査](../02-architecture/purchase-readiness-audit-2026-10-21.md)で、DS1/CADの26本の単軸が指定支持ブッシュ位置を通らず、軸受けされないことを確認しました。DS1の成形穴と5mm軸の固定条件も未定だったため、従来DS1全量BOMは購入候補から外しました。DSF1は高価格の比較候補として記録しています。いずれも新候補と同一の受入証拠にはしていません。
