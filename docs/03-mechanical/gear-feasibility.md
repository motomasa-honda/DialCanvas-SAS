# 単一モーター歯車列の成立性

## 現在の機械候補

静音モーター1基で装飾歯車列を動かします。7軸固定でも歯車数固定でもありません。現行mainの28位置は配置計算例です。

直近の機械候補は[KHK BSS1-20C・6mm軸支持案](bss20_axis_support_candidate-2026-10-22.md)です。型番を1つに揃え、6mm h7ピン、OILES 80B-0608、KSC0605、POMワッシャーを同じZスタックへ記載しました。全28位置の公称2D計算で最小ケース内余裕5.10mm、LCD有効円Ø87.6mmへの最小平面すき間12.19mm、支持ウェブ3.49mm、ワッシャーと開口のウェブ1.49mm、非隣接歯車間すき間1.59mmです。画面z=1.5–17、A/B歯面z=46–52/55–61mmで、画面を歯車より前に置きました。ケース奥行はモーター後端まで収めるため167mm候補へ増やしました。これらは公称包絡値で、実歯形、部品公差、軸振れ、板たわみ、配線、実負荷は未検証です。

再現用の[生成スクリプト](generate_bss20_axis_candidate.py)、[28位置/Z座標CSV](gear_axis_schedule_bss20_candidate.csv)、[配置SVG](irregular_layered_gear_layout_bss20_candidate.svg)、[A/B支持板穴配置SVG](gear_support_plate_A_bss20_candidate.svg) / [B](gear_support_plate_B_bss20_candidate.svg)、[筐体/表示/モーター包絡SCAD](bss20_clock_envelope_review.scad)を置いています。配置SVG/SCADは寸法図ではなくCAM出力でもありません。

## 現行候補と残作業

市販部品はカタログ仕様で選び、別体の圧入片・保持治具・4歯車試験片は初号機の前提にしません。KHK BSS1-20C付属のM4止めねじ、OILES 80B-0608、6mm h7ピン、Ø8 H7支持穴を使う候補は選定済みです。完成支持板にそのまま加工し、組立時に手で回して抵抗や割れがないか確認します。問題が出た箇所だけ直します。

表示器と歯車の前後順は[ADR-0020](../../adr/0020-display-first-axial-stack.md)で修正しました。残りは最終歯車数/配置（28位置は任意の計算例）、補助電装・ケーブルの同一座標統合、ケース最終寸法/外観加工図、一台分の数量・販売単位・加工費を含むBOMです。購入個体の基板リビジョン照合、独立圧入片、保持治具は購入前条件にしません。

一台分の配置と加工図が揃うまでは、ケース加工・最終数量の歯車/支持板発注を確定しません。型番選定済みの市販部品について、個体リビジョンの特定や独立試験片を購入条件にはしません。実機の手回し、低速動作、配線接触、温度の確認は組立後の通常受入です。

## 旧機械案の保留根拠

[購入前設計監査](../02-architecture/purchase-readiness-audit-2026-10-21.md)で、DS1/CADの26本の単軸が指定支持ブッシュ位置を通らず、軸受けされないことを確認しました。DS1の成形穴と5mm軸の固定条件も未定だったため、従来DS1全量BOMは購入候補から外しました。DSF1は高価格の比較候補として記録しています。いずれも新候補と同一の受入証拠にはしていません。
