# モーター・ドライバー接続案

## 選定した部品と公開仕様

| 部品 | 選定 | 設計に使う公開値 |
|---|---|---|
| ステッパー | Adafruit NEMA-8 #4411 ×1 | 4線バイポーラ、約406mmのリード線、色は個体差あり、巻線約7Ω/相、最大0.6A/相 |
| ドライバー | Adafruit TMC2209 breakout #6121 ×1 | VM 5–29V、4線モーター用ネジ端子26–20AWG、基板26.6×24.1×10.3mm、取付穴4か所 |
| ドライバー固定 | 背面着脱カバー内側の小型キャリア | 基板メーカー図面の取付穴中心間隔21.59×14.48mm。穴径は実装品/図面で最終照合 |
| 延長線 | UL1007 AWG22、4本。既存候補の赤/黒線を各2本使う | 22AWGは#6121の公開端子範囲内。各線にA1/A2/B1/B2の識別ラベルを付ける |

公開資料から型番と端子範囲を選定できるため、線径をメーカーへ問い合わせる必要はありません。#4411の実リード線が細くて端子に固定できない場合も、AWG22延長線へ個別にはんだ接続する案を採用し、#6121側はAWG22で統一します。リード線を端子へ無理に押し込む必要はありません。

## 接続方法

1. 無通電で4本のリード線間の抵抗を測り、約7Ωとなる2組を巻線A/Bとして記録する。色だけで組を決めない。
2. 各巻線をドライバー端子`1A/1B`、`2A/2B`へ接続し、線の両端に`A1/A2/B1/B2`ラベルを付ける。軸の回転方向が逆なら、片方の巻線の2本を入れ替える。
3. #4411の実線が#6121端子に確実に固定できる場合は直接接続する。範囲外またはクランプが不安定な場合は、各線をAWG22 UL1007へ個別にはんだ接続し、接続部を個別絶縁する。どちらも露出銅線を端子外へ残さない。
4. はんだ接続を使う場合は接続部を引張荷重のかからない位置へ置き、モーター側とドライバー側の両方を別の固定点で保持する。スプライスや端子をストレインリリーフとして使わない。
5. 配線はギア/軸の可動領域を避けて背面カバー沿いにまとめる。サービスカバーを開閉しても、端子を引っ張らずに作業できる余長を残す。

通電前に導通、巻線間の絶縁、端子の保持、VM極性を確認する。公開資料に指定締付トルクがない箇所へ任意の数値を設定しない。

## CAD配置候補

TMC2209 #6121の包絡を、背面着脱カバー内側、中心`X=+35mm, Y=+68mm`、内面`Z=121mm`へ配置しました。部品外形の保守包絡は`X=21.7…48.3mm, Y=56.0…80.1mm, Z=110.7…121mm`です。現行モーター本体は`X=-10…+10mm, Y=58…78mm, Z=81…114mm`の仮包絡なので、モーターと基板はX方向に約11.7mm離れます。基板は背面サービスカバーと一緒に取り外す想定です。

この位置は公開外形を使った候補で、端子ねじへ工具を当てる向き、固定キャリア、カバーの板厚/逃げ、コネクター/制御線、実際のリード引出し方向と曲げは受入前です。CADには基板包絡のみを入れ、未確認のケーブル曲線は描いていません。背面のモーター後方すき間は名目7mmのままなので、実リードがカバーに挟まらない固定/逃げを現物で決めます。

## 受入で確認すること

- #4411のリード線本数、色、被覆外径、撚線/単線、実長を記録し、抵抗測定で2組の巻線を特定する。
- #6121の4つのモーター端子に直接保持できるかを無通電で確認する。直接保持が不適ならAWG22スプライス案へ切り替え、はんだ部の絶縁と固定を記録する。
- 基板/端子を背面カバーへ仮固定し、ねじ回し、カバー脱着、線の逃げ、全可動部との離隔を確認する。
- ケーブル固定点を2か所設け、軽い引張りで端子/はんだ部へ荷重が伝わらないこと、カバー開閉で擦れ/挟み込みが起きないことを確認する。
- 0.30A RMS/相の初期設定で始動、正逆、停止、連続運転を行い、電流・温度・音・振動を受入計画へ記録する。
