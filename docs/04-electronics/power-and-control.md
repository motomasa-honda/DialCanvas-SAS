# 電源・制御の候補と確認事項

USB-C PDから固定電圧を受け、表示基板と照明向けの5V枝、モーター向けの別枝を設ける案を検討しています。現在の部品候補、型番、価格出典は[未選定部品表](../02-architecture/unselected-parts-procurement-plan-2026-10-21.md)を参照してください。候補表は発注許可でも安全設計完了でもありません。

## 電源境界

- 商用AC電圧は筐体内へ持ち込みません。適合する市販ACアダプターを候補にします。
- PD受電、電圧変換、枝ごとのヒューズ、コネクター、配線径、保持、極性は全負荷と故障条件を測ってから確定します。
- 表示器/Wi-Fiのピーク、モーター始動・拘束、LED、変換損失を分けて測り、最悪条件で電圧降下と温度を確認します。
- モーター枝の電流を表示基板のリターン経路へ流さない配線を設計します。

## モーター制御

TMC2209と小型ステッパーは候補です。Cコアは1.6rpm、200step/rev、1/8分割のSTEP周期を計算します。アプリの出力端子は既定で無効とし、正確な基板改版、GPIO、ドライバー端子、ENの外部安全状態を照合するまで有効化しません。独立した物理スイッチでモーター電力を遮断する構成も必要です。

現時点で安全回路、ヒューズ値、電源定格、基板の改版別GPIOを確定していません。DR-05の証拠が揃うまで通電評価や製作へ進みません。
