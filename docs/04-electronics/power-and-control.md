# 電源・モーター・LED 制御の初期設計メモ

現段階では表示器、制御基板、モーター、LED が未選定であるため、電圧・電流・回路定数を確定しない。構成検討では次を別負荷として測る。

| 負荷 | 取得する値 | 設計判断への用途 |
| --- | --- | --- |
| 円形表示器 | 常時表示時の平均/最大電流、輝度と温度 | 電源容量と放熱 |
| 制御基板・通信 | 起動時ピーク、Wi-Fi 送信時ピーク | 電源瞬低対策 |
| モーター/ドライバ | 始動、定常、停止・拘束時の電流 | 電源容量、保護、発熱 |
| 暖色 LED | 点灯時電流、温度、光量 | 抵抗/定電流方式、木部との熱距離 |
| 時刻バックアップ | 必要保持時間と電源断時消費 | RTC・バックアップ方式 |

時計表示と歯車制御の論理状態を分離し、モーター停止が表示更新を止めないことを検証する。モーターの電気ノイズ、表示器の瞬低、木製筐体内の温度上昇は試作で測る。電源入力、安全保護、配線経路、接地方式は部品選定後に回路図へ落とす。
