# 背面補助電装の取付・配線候補 v0.1

更新日：2026-10-22

状態：**接続の役割と取付方法の候補を整理。配線長、ケース穴、保持具の加工図、実機受入は未完了。購入・加工・製造指示ではない。**

## 前提

- 表示・主制御はWaveshare ESP32-P4 3.4C一体基板。別の表示/主制御基板は追加しない。
- この文書の補助電装は、着脱式背面カバー内側へ取り付ける候補。
- 座標と仮割当は[背面配置候補](rear-electronics-layout-candidate-v0.1.svg)を参照。外箱270×205×145mmは設計検討用の仮寸法で、未凍結。
- コネクター向き、線長、端末、ヒューズ保持具、スイッチ穴、カバーの厚みは推測で確定しない。

共通方針は、各基板の穴またはメーカー指定キャリアで機械保持し、背面カバーへ交換可能に取り付けることです。接着材だけで保持しません。基板の銅箔、はんだ面、端子、ジャンパへケースやねじが接触しない絶縁距離は実物に合わせます。部品を直接木材へ押し当てるか、特定のねじ長さを使うかは、座面と基板高さが揃ってから決めます。

### 配線束の分離と保持

- モーター相線とSTEP/DIR/ENN・RTCの信号線を、同じ束で長距離並走させない。交差が避けられない場合は短く交差させ、実機で表示/RTC/モーター動作を確認する。
- モーター電流の戻りを3.4CのGND配線やUSB-Cケーブルへ流さず、電源分岐点まで専用の戻り線を使う。
- 可動部、歯車列、軸穴、支持板の開口を横断するルートは採らない。サービスカバーの開閉で線を引っ張らない固定点を設ける。
- 各束は切断前に実物を仮配置して長さを測る。閉箱状態でのケーブル挟み込み、端子への引張り、コネクター抜け、放熱妨げを確認する。
- 3.4Cへの通常給電は9V分岐→#4092の特注5.2V出力候補→TPS25810搭載専用source基板→USB TO UART Type-Cの設計候補。#2851を表示sourceへ直結しない。EVMは製品内へ組み込まない。書込み/デバッグ時はsource cableを外してPCを接続し、二つの5V源を同時に接続しない。
- DS3231 #3013のI²CプルアップはVin基準。RTCは3.3Vで給電し、SDA/SCLが5Vへ引き上げられないことを確認する。

## 現物受入で閉じる範囲

背面サービス面の候補位置と配線の接続先は整理しましたが、実配線図/加工図はまだ出せません。次の実物確認を終えたら、基板の面向き、コネクター開口、保持具、ハーネス長、固定点を同じ座標の図面とBOMへ反映します。

1. 3.4C、完成したsource専用基板、#4411、各補助基板の実外形/端子向き/高さを仮配置へ重ねる。
2. USB-C入力/出力、専用source基板の電源入力、ヒューズ交換、スイッチ操作、RTC電池交換の作業空間を確認する。
3. 電源・モーター・制御・RTCの各線を仮這わせし、線長/端子/結束点/曲げ/カバー開閉を記録する。
4. 分岐極性、導通、短絡、PD契約、5V降下、ノイズ、電流、閉箱温度を受入計画に沿って測る。
