# 円形ディスプレイ比較計画

候補は円形の 2.8 型・3.4 型を含む OLED と IPS 液晶。型番、価格、供給、互換性は未確認で、ここでは採用を決めない。

| 評価項目 | OLED で確認すること | IPS で確認すること | 証拠 |
| --- | --- | --- | --- |
| 黒と発色 | 消灯画素の黒、色再現、斜め視認 | バックライト漏れ、コントラスト、色再現 | 同じ文字盤画像の昼夜実機比較 |
| 視認性 | 最小/最大輝度と暗室のまぶしさ | 同左、保護板越しの反射 | 照度条件を固定した写真と目視記録 |
| 寿命 | 静止目盛りの焼き付き、輝度低下、メーカー寿命条件 | バックライト寿命、ムラ | 一次資料と長時間表示試験 |
| 形状・寸法 | 有効表示径、外形、固定穴、厚み | 同左 | 寸法図と模型への当て込み |
| 制御 | IF、電圧、初期化、描画速度、メモリ | 同左 | データシートと最小描画試作 |
| 熱・電力 | 常時表示時の電流と表面温度 | バックライト電流と表面温度 | 実測ログ |

評価では同じ文字盤と針の動き、同じ保護板候補、昼夜の照度条件を使う。サイズの差は視距離と筐体レイアウトで判断する。OLED の焼き付きはリスクとして残し、試験条件と累積表示時間を記録する。制御基板との適合は、公開データシート照合だけでなく実機描画で確認する。
