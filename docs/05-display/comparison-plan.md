# 円形ディスプレイ候補と受入計画

現行候補はWaveshare ESP32-P4-WIFI6-Touch-LCD-3.4C、800×800円形IPS一体基板です。具体候補はADR-0009/0010、機械寸法の扱いは[基板インターフェース](../03-mechanical/display-board-interface.md)を参照してください。部品候補の存在や公開寸法は、実基板の採用・取付合格を意味しません。

## 実機で確認する項目

| 項目 | 受入方法 | 状態 |
| --- | --- | --- |
| 改版と外形 | 同じSKUの現物を公式寸法・回路図と照合 | 未確認 |
| 表示 | 800×800 JPEGと連続針、視野・昼夜・保護板反射を確認 | 未確認 |
| 描画周期 | 16ms要求でフレーム落ち、CPU/PSRAM使用量、温度を記録 | 未確認 |
| microSD | 文字盤追加、複数選択、抜差し、異常画像の復帰を確認 | 未確認 |
| 電力 | 起動・表示・Wi-Fiの最大/平均電流を測定 | 未確認 |
| 取付・整備 | 表示面、端子、カード、USB、保持部と保護板の隙間を確認 | 未確認 |

OLED比較や抽象的な型番比較は本機の採用証拠にしません。追加候補を検討する場合は同じ表示品質、寿命、電力、形状基準を使います。関連作業はDR-02とDR-03です。
