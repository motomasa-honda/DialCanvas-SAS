# microSD文字盤ファイルと滑らかな針の設計

## 採用仕様

表示・制御基板は Waveshare ESP32-P4-WIFI6-Touch-LCD-3.4C。公式資料の現行記載は**3.4型円形IPS、800×800**、microSD SDIO、ESP32-P4 + ESP32-C6、32MB PSRAM + 32MB Flash、USB-C、RTCバックアップ端子。Waveshare公式デモの検証範囲に合わせ、初期ソフトウェア基準をESP-IDF **v5.5.5**、Waveshare managed BSP **3.0.1**、LVGL **9系**に固定する。ユーザー画像のJPEG展開にはEspressif `esp_jpeg` **1.3.1**を使う。FATFS/SDIO、NVS、SNTP、JSONのcJSON、単調増加時計はESP-IDF標準機能を使う。

ESP-IDF/BSP/LVGL、JPEGデコーダー等の既製ソフトウェアは利用できるが、文字盤一覧・時刻補間・針描画・操作・エラー復帰を組み合わせる**アプリケーションファームウェアは本機用に実装が必要**。ファームウェア完成済みの既製時計製品を組み合わせる構成ではない。

一次資料：[Waveshare製品資料](https://docs.waveshare.com/ESP32-P4-WIFI6-Touch-LCD-XC)、[公式LVGL 9デモと対応IDF/BSP](https://github.com/waveshareteam/ESP32-P4-WIFI6-Touch-LCD-XC/blob/main/examples/esp-idf/08_lvgl_demo_v9/README.md)、[公式BSP/リビジョン監査](https://github.com/waveshareteam/ESP32-P4-WIFI6-Touch-LCD-XC/blob/main/docs/HARDWARE.md)、[Espressif JPEG Decoder](https://components.espressif.com/components/espressif/esp_jpeg/versions/1.3.1)。基板の実改版・P4シリコン改版に対するビルドと表示は、実機を入手後に確認する。

## microSD上の置き方

```text
microSD/
└── DialCanvas/
    └── faces/
        ├── Forest/
        │   ├── face.jpg
        │   └── dial.json   (任意)
        └── Night/
            └── face.jpg
```

| 項目 | 初期仕様 |
|---|---|
| カード | microSDHC 8〜32GB、FAT32。ファームウェアは文字盤領域を読み取り専用で使う。|
| ファイル名 | 各文字盤フォルダーに`face.jpg`を1枚。任意で`dial.json`を置く。|
| 一覧 | 起動時に`faces/`直下を走査し、ASCII英数字・`_`・`-`で1〜32文字のフォルダー名、通常ファイルの`face.jpg`、0バイト超〜8MiB以下の条件に合うものを候補にする。候補が32件を超えた場合も、名前順の先頭32件を登録する。画像の寸法・形式・デコードは選択時に検査し、読めない文字盤は飛ばす。|
| 画像 | 800×800px、sRGB、Baseline JPEG、最大8MB。Progressive JPEG、動画、アニメーションは対象外。円形画面に収め、余白は黒で表示。|
| 編集 | 既存の画像編集アプリで作成し、JPEGへ書出し。専用変換アプリは要しない。|
| 追加・削除 | 電源を切ってカードをPCへ移し、文字盤フォルダーをコピー/削除して安全に取り出す。内蔵の既定文字盤は削除できない。|
| 設定 | 任意の`dial.json`は針色・中心・長さ・太さだけを設定。省略・不正JSON時は既定値。|
| 再起動後 | 短押しで確定したフォルダー名を本体NVSへ保存。次回は保存済み、`Forest`、名前順先頭の順で選ぶ。カードがない/壊れている場合は簡易目盛り盤。|

ファイル構造の例：

```json
{
  "version": 1,
  "name": "Forest",
  "center": {"x": 0.5, "y": 0.5},
  "hands": {
    "hour": {"color": "#e9c27f", "length": 0.27, "width": 8},
    "minute": {"color": "#f4e7c9", "length": 0.37, "width": 5},
    "second": {"color": "#ef7547", "length": 0.42, "width": 2}
  }
}
```

中心座標`x/y`は画像幅/高さに対する0.0〜1.0の比率、針の`length`は800px画像幅に対する0.0〜0.5の比率（0.5で表示円の半径まで）、`width`は1〜32px、色は`#RRGGBB`で表す。設定可能なキーと範囲は[`dial.schema.json`](../../firmware/cots_clock_core/dial.schema.json)に固定し、コピーして編集できる[Forestサンプル](../../firmware/cots_clock_core/examples/Forest/dial.json)を用意した。設定ファイル内のパス・コード・任意の処理は受け付けない。ファイルが省略された場合やJSON/設定値が不正な場合は組込み既定値へ復帰する。未対応画像、壊れたJPEG、空フォルダー、カード不在時も既定盤で時計表示を続ける。ファームウェアからSDへの書込みは行わない。

## 針を滑らかに動かす

背景画像と時刻針を別レイヤーに描く。起動時は外付けAdafruit DS3231 #3013から有効な時刻を読み込み、Wi-Fi接続後のSNTP同期時にRTCを更新する。GPIO28/29・I2C1を候補とし、3.3V給電、CR1220はDS3231モジュール自身の電池ホルダーだけに装着する。Waveshare基板のRTC端子は充電式電池専用なので使わず、CR1220等の一次電池を挿さない。価格参考はRTC約¥3,150、CR1220約¥220。アプリソースとUTC変換コアは追加済みだが、I2C競合・実基板接続・起動復旧・長期保持は未試験。

時刻取得はRTC/SNTP、表示タイミングは単調増加タイマーから計算する。12時方向を0度、時計回りを正方向とする。各描画時点の小数秒を使って60fpsを目標、実測30fps以上を最低受入値として、秒針・分針・時針を連続補間する。LVGLのタイマー更新周期を時刻精度の基準にしない。画面更新が遅れた場合も次フレームでは現在時刻の角度を計算する。

針角度は同じ時刻値から計算し、秒・分・時の境界で段階的に飛ばさない。時針は分・秒、分針は秒も含めて補間する。表示用の高精度時刻はNTP/RTCの時刻と単調増加タイマーを組み合わせる。歯車モーターの停止、脱調、回転速度は時刻表示に影響させない。

1. microSDから画像を読込み、PSRAMへ表示用データを作る。
2. 針を描画する時刻角度をフレームごとに求める。
3. 前フレームとの差分を画面へ反映する。モーター停止状態やギア速度は時計表示へ影響させない。
4. 文字盤切替は次画像が完全に読めてから一括反映し、読込み中の黒画面・半端な絵を避ける。

800×800のRGB565全面画像でも約1.22MiB、32MB PSRAMには収まる計算。実際のフレームバッファ、LVGL描画バッファ、JPEG展開先、Wi-Fi、BSPの同時メモリーを実機で測る。表示回路の最大輝度・連続描画時の電流と温度も計測する。

## 操作

タッチ機能は使わず、押し込み付きロータリーエンコーダー1個で操作する。

| 操作 | 動作 |
|---|---|
| 回す | 一覧を前後に移動し、候補をプレビュー |
| 短押し | 表示中の候補を選択し、NVSへ保存 |
| 長押し | 歯車の回転を開始/停止（要求仕様）。現在の表示アプリは入力を認識するが、モーター出力・安全制御へはまだ接続していない |
| 独立スイッチ | モーター電源を物理遮断 |
| 背面スイッチ | 暖色LEDをON/OFF |

GPIO既定割当はA=2、B=3、SW=21で、[3.4C公式回路図](https://files.waveshare.com/wiki/ESP32-P4-WIFI6-Touch-LCD-XC/ESP32-P4-WIFI6-Touch-LCD-XC-Schematic.pdf)にある拡張端子から取得する。GPIO20/22はC6側との共用可能性を確認できるまで割当から外し、モーター信号はGPIO4=STEP、GPIO5=DIR、GPIO32=ENを暫定予約する。入力は内部プルアップ、共通接点はGNDとする。文字盤管理はPCでのmicroSD編集と本体エンコーダーに限定する。Wi-Fiは時刻同期に利用し、Web管理と音声操作は初号機に実装しない。電源を切ってカードを交換する。GPIO電圧、接点配線、エンコーダー応答、起動後の選択保持、SDなし/破損時の復帰は実機で確認する。

## 受入試験

- 一般的な画像編集アプリで作った800×800 JPEGを2枚以上登録し、PC専用変換なしで一覧・切替できる。
- 30fps以上で針が段階的に跳ねず、60fps目標で秒針・分針・時針が連続して見える。
- SDなし、未対応画像、破損JPEG、破損JSON、空フォルダー、カード抜去から既定文字盤と時刻表示へ戻る。
- SNTP同期時に外付けRTCが更新され、CR1220装着状態で長時間の主電源断後も時刻が復元される。RTC未設定・不在・OSF状態では時刻未設定として安全に扱い、SNTP成功後に復旧する。
- JPEG全体展開、2つ以上の切替、LVGL更新、RTC/NTPを同時実行してもPSRAM不足や表示停止がない。

ファイル形式・描画方式・ソフトウェア依存の基準版は設計確定。針角度コア、直交エンコーダー遷移/文字盤巡回コア、単一モーターの1.6rpm周期コア、DS3231 UTC変換コア、`dial.json` v1 Schema/例をホストテスト付きで用意した。独立アプリ`firmware/cots_clock_app/`にはWaveshare BSPの表示/SD初期化、JPEG読込、針描画、Wi-Fi/SNTP、GPIO2/3/21のエンコーダー入力、DS3231起動時読込とSNTP後更新、SD文字盤走査、プレビュー、短押し確定とNVS保存を追加した。外付けRTCはAdafruit #3013 + CR1220、I2C1 GPIO28/29の候補。GPIO20/22はC6信号との共用可能性を確認できるまで割当から外し、GPIO4/5/32はモーター信号用に暫定予約。長押し検出はモーター制御へ未接続。ESP-IDFツールチェーンが作業環境にないためアプリは未ビルド。文字盤切替、永続化、入力応答、RTC時刻保持、実機fps・電流・メモリー・SNTPの受入は未完了であり、ホストテストPASSを実機動作の合格とは扱わない。
