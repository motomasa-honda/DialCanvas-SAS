# アプリ状態と操作モデル

時計表示と装飾歯車を分離します。実装ソースは `firmware/cots_clock_app/`、ホスト検証可能な角度・入力・RTC・STEP周期ロジックは `firmware/cots_clock_core/` にあります。

| 入力/事象 | アプリの動作 | 永続化・未検証点 |
| --- | --- | --- |
| 起動 | NVSを初期化し、外部DS3231候補から時刻復旧、表示とmicroSDを初期化 | NVS異常で自動消去しない。RTC実機確認が必要 |
| SNTP同期 | Wi-Fi接続後に時刻を補正し、RTC候補へ反映 | 通信断、初回未同期、電源断の実機試験が必要 |
| エンコーダー回転 | microSD上の有効文字盤をプレビュー | 実GPIOのデバウンスと操作性は未試験 |
| 短押し | プレビュー文字盤を選択し名前をNVSへ保存 | 再起動後の保持は実機未試験 |
| 長押し | 実験的な単一モーターGPIO出力を切替 | ビルド既定は無効。GPIO/ENNの外部状態/物理遮断確認後のみ有効化 |
| 文字盤ファイル | JPEGと任意dial.jsonを読取専用で走査 | 実基板で容量、破損、描画性能を確認 |

文字盤画像はSDへ書き戻しません。時刻はUTCを基準に保持し、JST表示へ変換します。更新周期16msは描画要求値で、60fps達成や時間精度の実証ではありません。
