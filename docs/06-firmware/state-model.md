# 操作・保存状態の設計メモ

製品コードは未実装。文字盤と歯車の状態は独立させる。最小の永続状態は「選択中の文字盤 ID」とし、歯車の再起動時状態、LED の状態、時刻源の設定を保存するかは未決定。

| 操作または事象 | 要求される結果 | 試験観点 |
| --- | --- | --- |
| 文字盤の追加 | 有効な文字盤だけ候補に加える | 不正ファイル・容量不足時の失敗処理 |
| 文字盤の削除 | デフォルト文字盤は拒否する | 選択中文字盤の削除時の扱いは要決定 |
| 文字盤の切り替え | 表示を更新し、選択 ID を保存する | 再起動後の復元 |
| 歯車の ON/OFF | 歯車だけを切り替える | 時計表示が継続すること |
| 物理ボタン/Web の同時操作 | 一貫した最終状態にする | 優先順位・競合規則は要決定 |
| Wi-Fi 断・電源断 | 時計と設定の復旧方針に従う | 時刻源とバックアップ方式は要決定 |

針の動作方式は文字盤ごとに設定できるものとする。具体的なデータ形式、更新周期、画面ドライバはディスプレイと制御基板を検証後に決める。
