# 一台用筐体・組立資料の現在地

参照外形270×205×145mmで、前後から整備できる木製筐体を計画しています。CADと図面候補は `docs/03-mechanical/` にあります。表示基板外形、支持板、2層の歯車配置を描いていますが、基板の改版・実測、保護板、配線、ヒューズ、温度、原本外観との一致は未受入です。

## 受入前に残る作業

1. 承認済みVersion 1.0の原本と曲線外観、装飾位置を照合する。
2. 実基板、カード/USB端子、モーター、配線、保護板を含む実寸包絡を確定する。
3. 前後アクセス、板保持、歯車軸支持、指の到達防止、配線保持を模型または実寸試作で確認する。
4. 全負荷時の電流・温度・音・振動を測り、木部と保護板の距離を確定する。
5. BOM、加工図、固定具、組立順、検査項目を同じ確定部品で同期する。

CADは構成検討用で、加工ファイルや発注指示ではありません。DR-06が完了するまで製作リリースを行いません。
