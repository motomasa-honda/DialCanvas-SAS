# 組立・整備構造の検討計画

承認済み外観 Version 1.0 の原本を基準に、曲線フレームとキャビネットを分けて組み立てられる構造を検討する。無垢材は見える構造部、突板は寸法安定性を優先する面など、部位別の割り当てを試作で決める。

1. 表示器、歯車、LED、配線、保護板を含む積層模型を作り、幅 25〜35 cm・奥行 10〜15 cm の暫定範囲と高さを検証する。
2. 前面から保護板・表示器・見える歯車にアクセスできる手順を作る。背面から駆動部・電源・配線にアクセスできる手順を作る。
3. 保護板の素材、固定、反射、傷、熱膨張を比較する。直接見える LED や配線を避ける。
4. 木材の温湿度変化、歯車軸の位置精度、音・振動の伝達を試作で確認する。
5. 分解・再組立後に文字盤位置と歯車クリアランスが再現するか測る。

加工図、工具、接着・固定方法、部品表は未確定。評価結果と設計寸法が揃ってから作成する。
