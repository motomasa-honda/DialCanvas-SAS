# 一台用筐体・組立ベースライン

機械構成と名目寸法は[設計ベースラインv0.21](../10-desk-redesign/design-baseline-v0.21.md)を参照します。この文書は設計順序と必要な整備性を示し、加工指示ではありません。

## 名目構成

- 外形270×205×145mm、内寸候補246×181×121mm、壁厚12mm。
- 曲線部はウォールナット無垢材、広い化粧面はウォールナット天然木突板。木目方向、材厚/等級、芯材、仕上げ、調達先と切出しは製作図と外観原本を合わせて決定する。
- 透明PC 8mm支持板2枚を二層ギアの前後に配置。BSS1-20Cは6mm h7ピンで支持し、OILES 80B-0608を使う候補。初号機の前面保護板評価材は透明PC 3mm、周縁捕捉、着脱式押さえ縁とする。実製品のグレード、反射/傷、たわみ、指到達は未受入。
- 表示はWaveshare 3.4C SKU31523を中央へ。公式Drawingの円形外径Ø115mm、外周M4穴75×78.5mm、全厚の安全側包絡15.50mmを使用。最大矩形包絡は115×115mm、後面支持板の120×120mm開口を通す。
- 28歯車二層CAD、6mm軸、ブッシュ、単一モーター、後部カップリングの名目位置は[BSS20包絡モデル](../03-mechanical/bss20_clock_envelope_review.scad)と[軸配置CSV](../03-mechanical/gear_axis_schedule_bss20_candidate.csv)を参照する。数量は要求値ではない。
- Z基準は前ガード内側面z=0。A支持板z=7–15、A歯面z=24–30、B歯面z=33–39、B支持板z=48–56、表示ガラス前面z=44.50mm候補（包絡はz=44.50–60.00）、継手z=57–79、モーター取付面z=81mm候補。
- 表示ガラス前面とB歯面終端の名目軸方向すき間は5.50mm。表示モジュールは後面支持板を中央開口から通る。外周M4穴は支持板開口内にあるため、開口をまたぐ保持キャリアを別に設ける。現物ねじ仕様、キャリア/背面部品干渉、歯車振れ/板たわみ込みのすき間は未受入。
- NEMA-8 #4411の付属リード線は約406mm・4芯。現行CADは配線/ドライバー基板位置を含まず、モーター後方の7mm名目すき間だけで配線成立を判断できない。
- 背面板をねじ止めで外し、microSD、USB/UART、RTC、PD/配線の点検を行える案。

## 構成設計上の組立順

支持板は252×187mm、ケースの内寸開口は246×181mmで、板が各辺3mmずつ壁に入ります。したがって支持板は、四辺を組み終えたケースへ前後から差し込めません。現行の組立候補は、溝加工したケース壁を支持板A/Bの周囲で組み、前後カバーを最後に固定する方法です。支持板は前後カバーから点検できますが、支持板自体を交換するにはケース壁の接合を開く必要があります。壁材の加工/接合方法がこの順序を成立させない場合は、本番加工前に溝保持方式をレール/ブラケットへ変更して再設計します。

1. ケース各壁を別部材として製作できる図面にし、ウォールナット壁の溝、支持板位置、コーナー接合、前後サービスカバーを同一外形基準で定義する。支持板を後入れできる前提の図面は発行しない。概念参照JPGは旧概寸を含むため、曲線の加工輪郭は寸法入り原本から起こす。
2. BSS1-20Cの1軸でM4×4止めねじ保持を確認し、同一PC材の穴試験片で80B-0608圧入と回転抵抗を確認する。
3. 同じ側壁材の試験片で8.2mm幅×3.2mm深さ候補溝を確認する。支持板/側壁の双方がPASSしてから4歯車板を加工する。
4. 後面支持板と正確な表示器改版の実寸、USB/SDの抜差し、端子高さを確認する。モーター付属線の線径とTMC2209端子適合、歯車/軸/板に触れない曲げ・固定・ストレインリリーフもモデルと配線図へ反映する。
5. 軸、ブッシュ、ギアを無通電で組み、4歯車試験から全列手回しへ進み、逆転、面間隔、歯面/板/表示ガラス干渉を確認する。
6. モーター、カップリング、独立VMスイッチを取り付け、共通軸の軸方向保持、配線保持と背面アクセスを確認する。
7. 電源枝・LED・保護板を組み、指到達、光源直視、閉箱温度、配線擦れを評価する。
8. 外観原本と照合し、BOM、加工図、組立票、検査票の改版をそろえる。

## 製作図へ進む条件

1. 承認済みVersion 1.0の寸法入り外装原本、Forest Guardianの高解像度文字盤素材、利用条件を確認する（FG-038）。概念参照JPGだけでは加工輪郭を作らない。
2. 正確な表示基板改版、USB/SD端子、モーター、配線、保護板の現物包絡を反映する。
3. 保護板の保持、たわみ、指到達防止、清掃/交換、前後整備を実寸で確認する。
4. 音、振動、全負荷電流、木部/PC/部品の温度を評価する。
5. DR-01〜06の証拠と残余リスクをレビューする。

CAD・配置SVGは公称形状の候補資料で、CAMへ直接渡す加工データではありません。DR-06の物理受入がPASSするまでは製作リリースDR-07をHOLDとします。
