# 一台用筐体・組立ベースライン

機械構成と名目寸法は[設計ベースラインv0.21](../10-desk-redesign/design-baseline-v0.21.md)を参照します。この文書は設計順序と必要な整備性を示し、加工指示ではありません。

## 名目構成

- 一台用の名目外形270×205×172mm、内寸246×181×148mm、側壁12mm。幅/高さ/奥行は内部スタックと選定部品の予約域に基づく。
- 曲線部はウォールナット無垢材、広い化粧面はウォールナット天然木突板。木目/材等級/芯材の候補と価格はかない製作所の見積で選ぶ。仕上げは自然色・艶消しクリア、染色なしを見積基準にする。
- 透明PC 8mm支持板2枚を二層ギアの前後に配置。BSS1-20Cは6mm h7ピン/OILES 80B-0608で支持する。前面ガードは光 KPAC303-1透明PC 3mmを周縁捕捉し、着脱式押さえ縁で保持する。
- 表示はWaveshare 3.4C SKU31523を中央へ。公式Drawingの円形外径Ø115mm、外周M4穴75×78.5mm、全厚の安全側包絡15.50mmを使用。ガラス前面z=1.5mm、基板後端z=17mmで、前面支持板AのØ119mm開口を通す。個体リビジョン照合は購入条件にしない。
- 28歯車二層CAD、6mm軸、ブッシュ、単一モーター、後部カップリングの名目位置は[BSS20包絡モデル](../03-mechanical/bss20_clock_envelope_review.scad)と[軸配置CSV](../03-mechanical/gear_axis_schedule_bss20_candidate.csv)を参照する。数量は要求値ではない。
- Z基準は前ガード内側面z=0。表示器z=1.5–17、PCキャリアz=19–22、A支持板z=29–37、A歯面z=46–52、B歯面z=55–61、B支持板z=70–78、Bカラーz=79–84、継手z=84–106、モーター取付面z=108、本体後端z=141、後壁内面z=148。
- 表示器は歯車より前。外周M4穴と支持板Aの4点をつなぐキャリア候補は[表示基板インターフェース](../03-mechanical/display-board-interface.md)に定義した。ネジ掛かり、USB/SD操作、線の通し方、キャリア/板たわみは完成品組立時に通常確認する。
- NEMA-8 #4411の付属リード線は約406mm・4芯。TMC2209 #6121は背面着脱カバー内側の候補位置をCADへ追加済み。端子へ直接固定できない場合にAWG22 UL1007へ個別はんだ接続する案を[配線仕様](../04-electronics/motor-harness-interface.md)に定義した。配線包絡/固定点は現物受入前。
- 背面板をねじ止めで外し、microSD、USB/UART、RTC、PD/配線の点検を行える案。

## 構成設計上の組立順

支持板は252×187mm、ケースの内寸開口は246×181mmで、板が各辺3mmずつ壁に入ります。したがって支持板は、四辺を組み終えたケースへ前後から差し込めません。現行の組立候補は、溝加工したケース壁を支持板A/Bの周囲で組み、前後カバーを最後に固定する方法です。支持板は前後カバーから点検できますが、支持板自体を交換するにはケース壁の接合を開く必要があります。壁材の加工/接合方法がこの順序を成立させない場合は、本番加工前に溝保持方式をレール/ブラケットへ変更して再設計します。

1. ケースの外寸/内寸、P1波形下辺、P2/P3溝、P4開口は[見積図A01/A02 v0.2](../03-mechanical/walnut_case_candidate-2026-10-22.md)へ指定済み。見積回答で木工所標準の接合/ガード保持を決め、支持板を先に差し込める未組立キットとして依頼する。
2. 完成支持板A/BへØ8 H7穴を加工し、28位置配置を本一台の数量基準としてブッシュ・軸・歯車・カラー・ワッシャーを組む。個別クーポンや4歯車板は作らない。
3. 前面ガード、表示基板と四本腕キャリアを組み、M4×8基板ねじ4本、2mm絶縁スペーサ4個、M3×25支持ねじ4本と7mm支持スペーサ4組で固定する。
4. 支持板2枚を側壁/上下壁の9×4mm溝へ入れ、PETシムで軽く保持した後、ケースを閉じる。溝保持を目的に別体試験片は作らない。
5. モーター/継手をz=108mm取付面へ固定し、継手z=84–106mm、モーター後端z=141mm、後壁内面z=148mmを使う。
6. 背面電装とハーネスを配置図どおり組む。線は実際の通路に沿って切り、モーター相線と信号線を分け、背面カバーに固定点を設ける。
7. 通電前に極性/短絡/端子保持を確認し、表示・RTC・入力・歯車手回し・低速駆動・LEDを順に動作確認する。
8. 低速/全負荷で滑り、噛み込み、異音、線の接触、電圧降下、温度を記録し、異常箇所だけ修正する。

## 製作図へ進む条件

1. ケース見積図v0.2を使い、ユーザー指定のかない製作所から一台分キットの価格/納期/送料を取得する。問い合わせは未送信。
2. 見積回答に応じて木目/材等級、接合、保持金物を選び、必要な場合だけ寸法図へ反映する。
3. 完成品の組立後に、表示/SD/操作、支持板と歯車の手回し、保護板、配線保持、電源/温度を通常受入として確認する。
4. 高解像度文字盤素材と利用条件はFG-038のソフトウェア/意匠作業として確認する。機械部品のカタログ選定は止めない。

CAD・配置SVGは公称形状の候補資料で、CAMへ直接渡す加工データではありません。DR-06の物理受入がPASSするまでは製作リリースDR-07をHOLDとします。
