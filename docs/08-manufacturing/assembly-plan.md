# 一台用筐体・組立ベースライン

機械構成と名目寸法は[設計ベースラインv0.21](../10-desk-redesign/design-baseline-v0.21.md)を参照します。この文書は設計順序と必要な整備性を示し、加工指示ではありません。

## 名目構成

- 外形270×205×145mm、内寸候補246×181×121mm、壁厚12mm。
- 曲線ウォールナット無垢フレームと部位別のウォールナット突板。
- 透明PC 8mm支持板2枚を二層ギアの前後に配置。前面保護板は透明PC 3mm、周縁捕捉、着脱式押さえ縁を候補とする。
- 表示はWaveshare 3.4C (115×115mm公称外形)を中央へ。後面支持板の120×120mm開口、ガラス面z=40mm。
- 28歯車二層CAD、5mm軸、ブッシュ、単一モーター、後部カップリングの名目位置は機構図を参照する。数量は要求値ではない。
- 背面板をねじ止めで外し、microSD、USB/UART、RTC、PD/配線の点検を行える案。

## 構成設計上の組立順

1. ウォールナットケースと溝、支持板保持、背面サービス開口の図面を同一外形基準で作る。
2. 同一材料/厚みの試験片でPC穴・溝、ブッシュ圧入、歯車穴、ねじ端距離を決める。
3. 後面支持板と表示器の実寸、USB/SDの抜差し、ケーブル曲げと端子高さを確認する。
4. 軸、ブッシュ、ギアを無通電で組み、全歯車の手回し、逆転、面間隔、板干渉を確認する。
5. モーター、カップリング、独立VMスイッチを取り付け、配線保持と背面アクセスを確認する。
6. 電源枝・LED・保護板を組み、指到達、光源直視、閉箱温度、配線擦れを評価する。
7. 外観原本と照合し、BOM、加工図、組立票、検査票の改版をそろえる。

## 製作図へ進む条件

1. 承認済みVersion 1.0参照原本、Forest Guardianの高解像度文字盤素材、利用条件を確認する（FG-038）。
2. 正確な表示基板改版、USB/SD端子、モーター、配線、保護板の現物包絡を反映する。
3. 保護板の保持、たわみ、指到達防止、清掃/交換、前後整備を実寸で確認する。
4. 音、振動、全負荷電流、木部/PC/部品の温度を評価する。
5. DR-01〜06の証拠と残余リスクをレビューする。

CAD・配置SVGは公称形状の候補資料で、CAMへ直接渡す加工データではありません。DR-06の物理受入がPASSするまでは製作リリースDR-07をHOLDとします。
