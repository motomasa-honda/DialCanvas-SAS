# Phase 1 への移行条件

Phase 1 に進む前に、以下の証拠を揃えてレビューする。全ての製品要求が完成・合格したことを意味せず、試作設計を始められるだけの判断材料を求める。

1. 承認済み外観 Version 1.0 と文字盤意匠の原本・利用条件が確認され、寸法変更が承認外観を侵さないことを説明できる。
2. 円形 OLED と IPS、2.8 型と 3.4 型を含む候補を同じ基準で比較し、選定候補のデータシートと入手経路を記録する。
3. 表示器と制御基板の電気・通信・描画性能の互換性を一次資料と最小試作で確認する。
4. 外形高さを含む内部レイアウトを作り、前後整備、保護板、歯車、電源、配線の干渉を確認する。
5. 歯車の正逆回転、10〜60 秒/回転、必要トルク、騒音、連続運転の成立性を試作で評価し、第一候補を継続するか ADR で判断する。
6. 電源、モーター、LED の負荷と熱、時計と歯車の制御分離、停電時の振る舞いをブロック図と試験計画に落とす。
7. 文字盤ごとの針動作、既定盤保護、選択保持、Web/ボタン操作の状態モデルと検証方法を定義する。
8. [未決定事項](../01-requirements/open-questions.md) の各項目に判断または明示的な Phase 1 実験計画があり、[リスク](../01-requirements/risks.md) の高評価項目に担当と低減策がある。
9. `python3 tests/check_design.py` が成功し、要求と検証項目の対応に欠落がない。

判断結果は日付、証拠へのリンク、残余リスクを記したレビュー記録として保存する。部品選定や CAD 完成をこの文書だけで宣言しない。
