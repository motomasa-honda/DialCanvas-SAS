# 試作・製作リリース条件

このゲートは、構想図やコードがあることだけで試作・完成を宣言しないためのものです。現在の作業状態は[新設計一覧](../10-desk-redesign/worklist.csv)を参照してください。

## 設計・ソフトウェアの証拠

- 要求台帳、旧設計との移行表、ADR、CAD、部品候補、ソース、ホストテストが同じ単一モーター方針を示す。
- ESP-IDF 5.5系の対象ビルドが成功し、依存部品と対象基板改版を記録する。
- 時計表示・文字盤・microSD・選択保持・SNTP/RTCを対象基板で確認する。
- 候補GPIO、ドライバーのEN安全状態、独立した物理遮断を資料と現物で照合する。

## 実機・製造の証拠

- 歯車列の始動/停止、方向、周期、トルク、連続運転、騒音、温度を記録する。
- USB-C入力、全枝保護、配線、最大電流、電圧降下、異常停止、閉箱温度を確認する。
- 外観原本、最終外形、表示取付、保護板、前後整備、木工、BOM、加工図を相互照合する。
- 全ての残余リスクと手順をレビューし、購入・加工・通電・実機書込みの個別受入を記録する。

文書検査やホストCテストはゲートの一部だけです。DR-01〜06の証拠が揃う前はDR-07を `HOLD` のままにします。
