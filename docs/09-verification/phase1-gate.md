# 試作・製作リリースゲート

現在の設計ベースラインは[Desk Edition v0.21](../10-desk-redesign/design-baseline-v0.21.md)、個別状態は[worklist.csv](../10-desk-redesign/worklist.csv)を参照してください。このゲートは設計文書、ソフトウェア検証、物理受入を分けて扱います。

## 設計ベースラインで確認する事項

- 要求台帳、要求移行表、ADR、CAD、部品候補、電源経路、ファームウェアが単一モーター/歯車数非固定の方針を共有している。
- 旧7軸ブランチと旧`execution/`の記録を現行の実装/受入証拠として参照していない。
- ESP-IDF v5.5.5 / ESP32-P4の安全既定設定・モーター有効設定ビルド、ホストCテスト、文書整合検査の結果を記録する。
- PROVISIONALの値とOPENの物理条件が、DR作業一覧および要求/OQと同期している。

## 物理受入で記録する事項

詳細な手順、計測条件、暫定判定基準は[一台試作受入計画v0.21](prototype-acceptance-plan-v0.21.md)に従います。

- 正確な基板改版、電源/USB/UART/SD/表示、GPIO、ENNの対応。
- JPEG表示、選択保存、起動、針フレーム周期、SNTP断、RTC保持。
- 歯車の噛合い、始動/停止、方向、周期、連続運転、音、振動、温度。
- USB-C PD契約、全負荷、枝保護、電圧降下、TVS、配線、閉箱温度、故障停止。
- 外観原本、外形、表示取付、保護板、前後整備、BOM、加工図、組立/検査票。

## 判定

文書検査やホストCテストは物理受入を代替しません。DR-02〜06のValidationStatusがPASSになり、残余リスクレビューと個別の製作許可が記録されるまではDR-07を `HOLD` とします。設計候補がベースライン化されても、購入・加工・通電・実機書込みの承認にはなりません。
