# 一台試作受入計画 v0.21

- 適用: [設計ベースラインv0.21](../10-desk-redesign/design-baseline-v0.21.md)
- 状態: **計画書。試験を実施した記録ではない**
- 対応作業: DR-02〜06
- 実機受入の開始記録: [PV-2026-10-21-01](physical-validation-log-2026-10-21.md)（開始記録。測定結果はまだない）

この計画は同一の部品改版、ファームウェア設定、測定条件で受入証拠を残すためのものです。試験前に購入、加工、通電、書込みの個別許可が必要です。作業状態を受入済みに変更する場合は生データと写真/波形を証拠ファイルへ保存します。

ここで提案する数値閾値（例: 30fps、24時間保持、騒音30dBA、表面温度45°C、入力2.4A）は試作判定用の暫定値です。要求台帳の `FIXED` 要求やユーザー承認値ではありません。実機計測と意匠・使用感のレビュー後に承認または改定し、承認前は合否を確定しません。

## 1. 試験記録の必須項目

各試験票に次を記録します。

- 試験ID、日付、担当者、要求ID、DR ID、試験前提/安全確認
- 実部品の製造者、完全型番、基板改版、ファームウェアcommit、menuconfig
- 電源、ケーブル、ヒューズ値、配線長/径、ジャンパ/スイッチ位置
- 測定器の型番、校正期限、接続点、測定間隔
- 周囲温度/騒音、負荷条件、開始/終了時刻
- 生の値、波形/写真、合否、未解決事項、関連要求/OQ

## 2. DR-02 — 表示基板とGPIO

| 手順 | 測定/確認 | 合格条件 |
| --- | --- | --- |
| D2-1 | 公開カタログDrawingを基準に、SKU31523をキャリアへ通常組立。4点のねじが無理なく締まり、USB/microSDへ手が届くことを確認 | 個体リビジョンの特定は求めない。取付やポートに大きな不一致があれば、ケース加工前にキャリア側を調整 |
| D2-2 | GPIO2/3/21 encoder、28/29 RTC、4/5/32 motor候補の競合、入力/出力能力、起動時strap/共用を確認 | 競合なし。割当と外部部品が基板資料と一致し、変更があればソース/設定/ADRを同時更新 |
| D2-3 | USB TO UARTから5V給電。40-pin 5V注入なし。SD、表示、UARTを個別接続 | 起動、表示、SD、UARTが期待どおり。異常電圧、予期せぬ再起動なし |

CIのESP-IDFビルドPASSだけではD2-1〜3を合格にしません。

## 4. DR-04 — モーター、歯車、音、温度

**2026-10-22優先順位更新:** 初号機では専用保持治具・独立試験片を発注前条件にしません。一台分をまとめて組み、組立時の目視/手回し/電流制限低速運転で適合を見ます。下記の0.06N·m治具手順は不具合調査が必要な場合の予備手順です。異常のない合格証拠を捏造せず、初回組立時の記録を残します。[購入前設計監査](../02-architecture/purchase-readiness-audit-2026-10-21.md)も参照。

| 試験 | 条件 | 合格条件 |
| --- | --- | --- |
| D4-1 | 一台分の機械を組み、歯車/軸へ合いマークを付ける。無通電で全列を手回しした後、電流制限した低速でモーターを運転し、全歯車を観察する | 割れ、歯車滑り、歯飛び、噛み込み、支持板/ワッシャー擦れ、配線接触がない。異常があれば停止し、原因箇所のみ追加確認 |
| D4-2 | TMC2209 #6121を0.30A RMS/相候補、1/8分割、1.600rpm指令 | motor shaft平均1.600rpmの指令に一致。各ギア周期は10〜60秒範囲。方向が設計どおり |
| D4-3 | スイッチOFFで電源印加、ONにしてもソフト要求なし、reset/brownout、出力有効設定起動 | 未要求/リセット/異常でENN HIGH、意図しないSTEP/相出力なし。SPST OFFでVM供給が切れる |
| D4-4 | 100回の始動/停止、正逆の目視、拘束を加えず無負荷/全列で比較 | 脱調/歯飛び/軸抜けなし。指令停止後に再始動できる。異常時は独立スイッチで停止できる |
| D4-5 | 24時間連続運転、周囲25±2°C。ケース外面/モーター/ドライバー/支持板を測温 | 過熱/変色/臭気なし。触れる外面≤45°Cを暫定基準、各部品はメーカー温度定格内 |
| D4-6 | A-weighted SPLを距離1mで測定。暗騒音≤25dBA、背景と動作中を各5回 | 騒音≤30dBAを暫定目標。測定値とユーザーの静音レビューを併記し、耳障りな周期音があれば不合格 |
| D4-7 | #4411の巻線ペアを抵抗測定で識別し、色/線径/被覆を記録。#6121端子へ直接固定できるか確認し、保持が不安定ならAWG22延長線へ個別はんだ接続する。カバーを脱着して配線を確認 | 4本をA1/A2/B1/B2として識別し、直接またはAWG22変換線が確実に保持される。素線露出/ほつれなし。別固定点で引張荷重を受け、線が歯車・軸・支持板・鋭利な木口へ触れず、カバー開閉/整備を妨げない |

歯数、配置、トルク余裕、TMC電流は計測に合わせて見直します。歯車数28個への固執はしません。4歯車の市販部品小計は価格スナップショットで¥10,109ですが、同材試験片/試験板の加工費は別途です。候補ノートに記載した価格・数量は発注指示ではありません。

## 5. DR-05 — 電源と保護

| 試験 | 条件 | 合格条件 |
| --- | --- | --- |
| D5-1 | Anker 511 + HUSB238を接続し、電源表示またはPD analyzerで入力契約を確認 | 15V/2A契約。表示されない場合は通電先を外し、HUSB238設定とケーブルを見直す |
| D5-2 | DFR0758 USB-AからMPA-ACECSS03BKを通して3.4C USB TO UART Type-Cへ給電 | 3.4Cが起動し、表示器端の電圧を記録。電圧が不安定、発熱、再起動があればその枝を停止して配線/部品を見直す |
| D5-3 | 画面最大輝度、Wi-Fi送信、microSD読み込み、LED、モーターを同時に通常動作させる | 表示・時刻・操作・歯車が安定し、PD契約切れや再起動がない。PD入力が15V/2A枠を超えない |
| D5-4 | DFR0758、DFR1015、#2851の入力/出力と3.4C端を確認 | 各モジュールがカタログ設定どおりの電圧を出し、全負荷で表示/SD/Wi-Fi/モーターが停止しない。電圧/電流と各モジュール温度を記録 |
| D5-5 | 組立後にヒューズ・極性・配線固定を点検し、通常負荷の枝電流を測る | ヒューズ定格が配線/端子/実負荷に合い、過熱/短絡/導線露出がない。意図的な短絡試験は行わない |
| D5-6 | モーター急停止/無通電手回しによるVM過渡をオシロスコープで計測 | VMピークがTMC2209絶対最大29Vを下回り、目標24V以下を維持。TVS/ドライバー温度に異常なし |
| D5-7 | 閉箱で最大輝度/Wi-Fi/LED/モーターを同時に動かし、安定して温度が落ち着くまで運転 | 再起動・PD再契約・異臭・異常な熱がなく、部品定格内。通常の連続使用で熱が上がり続ける場合は不合格として配線/配置を直す |

試作ヒューズ候補は入力3A、モーター2A、5V補助枝4A、LED2A（Littelfuse MINI 297 MIN3/MIN2/MIN4）。表示器sourceはDFR0758の内蔵保護を使用します。実測で配線/端子/ヒューズが不適合なら値を見直し、完成BOMと配線図を同時更新します。

## 7. リリース判定

DR-02〜06をPASSとするには各試験票に合否根拠と測定生データが必要です。CAD、BOM、CI、机上電力予算だけでは物理受入を完了しません。証拠レビューと残余リスク記録が揃うまでDR-07はHOLDです。
