# 要求と検証項目の対応

対応の正本は[要求台帳](../01-requirements/requirements.yaml)の `verification` 欄です。旧設計の要求FG-025/041/042は `SUPERSEDED`、購入候補や実機で受け入れていない機能は合格扱いにしません。

| 検証 ID | 対象要求 ID | 方法・記録 |
| --- | --- | --- |
| V-01 | FG-001〜FG-009 | 外観原本、寸法、木材・保護板、前後整備の実物確認 |
| V-02 | FG-010〜FG-016, FG-045〜FG-046 | 意匠、文字盤追加/切替/保持、針描画と実機表示 |
| V-03 | FG-017〜FG-020 | 表示器一次資料、昼夜視認、描画性能、電流・温度 |
| V-04 | FG-021〜FG-024, FG-026〜FG-029, FG-044, FG-050 | 不規則歯車配置、単一駆動、回転方向・周期、負荷・音・温度 |
| V-05 | FG-030〜FG-031, FG-043 | 暖色間接照明、反射、操作、木部温度 |
| V-06 | FG-032〜FG-036, FG-046, FG-048 | エンコーダー、独立スイッチ、制御分離、時刻・SD・電源断試験 |
| V-07 | FG-037〜FG-039 | Git履歴、参照原本・権利、要求/作業台帳整合性 |
| V-08 | FG-049 | BOMの販売元・型番・価格・寸法根拠、専用製作品の必要性 |

対応表とIDの整合性は `python3 tests/check_design.py` で確認します。PASSは文書の対応確認であり、実機・安全・加工の合格を意味しません。
