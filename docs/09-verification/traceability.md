# 要求と検証項目の対応

対応の原本は [要求台帳](../01-requirements/requirements.yaml) の `verification`。ここでは検証対象をまとめる。`OPEN` の要求は決定時に検証内容を具体化する。`REJECTED` と `SUPERSEDED` は現在の製品受け入れ試験対象から除外する。

| 検証 ID | 対象要求 ID | 方法・記録 |
| --- | --- | --- |
| V-01 | FG-001〜FG-009 | 承認外観原本、寸法図、木材/保護板試験、前後整備模型 |
| V-02 | FG-010〜FG-016, FG-042 | 意匠レビュー、文字盤追加/削除/切替、既定保護、再起動、針動作 |
| V-03 | FG-017〜FG-020 | 表示器一次資料比較、昼夜視認、焼き付き、描画試作 |
| V-04 | FG-021〜FG-029 | 歯車配置、方向、周期、トルク、滑り、騒音、連続運転 |
| V-05 | FG-030〜FG-031, FG-043 | 暖色/間接照明、点灯安定性、反射と操作 |
| V-06 | FG-032〜FG-036 | 物理ボタン、Web、制御分離、時刻・設定の停電/通信断試験 |
| V-07 | FG-037〜FG-039 | Git 差分、原本・権利確認、資料整合性 |

各検証の具体的な合否基準と測定記録は、部品・寸法の選定後に設定する。現段階で合格済みを意味するものではない。[Phase 1 移行条件](phase1-gate.md) を参照。
