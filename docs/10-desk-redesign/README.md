# Forest Guardian / DialCanvas Desk Edition

現行設計の正本は[設計ベースライン v0.21](design-baseline-v0.21.md)です。ここでは、製品の固定方針、候補部品、電気・機械インターフェースを一つにまとめています。

## 現行方針

- 静音モーター1基で複数の装飾歯車を連動させる。7軸固定ではなく、歯車数も固定しない。
- 28個の二層歯車CADはレイアウト候補であり、製作図ではない。
- 時計表示は3.4型円形ディスプレイ上で独立して動き、文字盤はmicroSDから選択する。
- 電源、安全経路、部品、寸法のうち未受入のものは `PROVISIONAL` として記録する。
- 旧7軸の設計ブランチと`execution/`の記録は履歴・参照専用。新設計の更新先・完了証拠として使わない。

## 受入状態

設計文書の整備状態と実機検証の状態は[作業一覧](worklist.csv)の別列で管理します。現行の要求状態は[要求台帳](../01-requirements/requirements.yaml)、未完了条件は[未決定事項](../01-requirements/open-questions.md)、設計判断は[ADR](../../adr/README.md)が正本です。

`DR-00/01/08`は方針・ソース統合・要求移行を完了し、`DR-02〜06`は候補設計をベースライン化していますが、現物の照合・動作受入は残ります。`DR-07`製作リリースはHOLDです。

DR-02〜06の段階手順、記録項目、暫定pass条件は[一台試作受入計画v0.21](../09-verification/prototype-acceptance-plan-v0.21.md)を参照してください。そこに記載した数値目標も、実機で確認・承認するまでは暫定値です。

要求の元記録として、旧v0.8の43要求を現行v0.21へ対応させた[要求移行表](requirements-migration-v0.8-to-v0.21.csv)を保存しています。旧7軸の要求と証拠は現行進捗へ流用しません。
