# Forest Guardian / DialCanvas Desk Edition — 新設計基準

状態: **現行設計ベースライン**

基準日: 2026-10-21

このフォルダーを、新しい置き時計設計の現在の記録と進捗管理に使う。旧7軸設計の記録は履歴として保持するが、この設計の作業項目や進捗率には流用しない。旧資料との対応は [現状記録](status-2026-10-21.md) を参照する。

## 目的と保持する製品要件

- 個人製作の高級置き時計。初回に作る個体を完成品として仕上げる。
- 木製筐体を中心に、承認済み Forest Guardian の外観、ウォールナット、アンティークブラス、暖色の間接照明を維持する。
- 外形は **270 × 205 × 145 mmを参照寸法**として扱う。内部部品、保護板、配線を収めた最終寸法は実測後に確定する。
- 中央に円形ディスプレイを配置し、時計の針は画面上に描画する。滑らかなスイープ表示を目指す。タッチ操作は不要。
- 文字盤画像は microSD から追加・切替できる。既定文字盤の保護と再起動後の選択保持を行う。
- 時計表示と装飾歯車の動作を分離し、歯車を止めても時計表示の時刻精度に影響させない。
- 安全性と入手性を優先して既製品を組み合わせる。購入・加工・通電・書込みは設計継続の指示から自動的に許可されたものと解釈しない。

## 駆動方針

- **7軸固定ではない。歯車ごとの独立駆動も要求しない。**
- 現行の新設計は、静音ステッパー1基で装飾歯車群を連動させる方針で進める。
- TMC2209 は現時点のドライバー候補で、採用部品としての確定・実機評価は未完了。
- 歯車数に固定値はない。約28個は配置検討上の案にすぎず、確定仕様ではない。
- 正逆回転の混在、歯車の連動経路、始動トルク、音、温度は、部品と実寸レイアウトを確定して検証する。
- 装飾歯車は時計の時刻計測に使わない。

## 現在の候補と未確定事項

| 項目 | 現在の扱い | 確定に必要な証拠 |
| --- | --- | --- |
| 円形表示器 | 3.4型 Waveshare ESP32-P4-WIFI6-Touch-LCD-3.4C を候補として継続 | 正確な改版、外形・取付、実表示、描画速度、電力・温度 |
| ステッパー駆動 | 静音ステッパー1基＋TMC2209を候補とする | 実型番、電流・トルク、歯車比、音・温度 |
| 文字盤形式 | `face.jpg` と任意の `dial.json` をアプリへ実装。Cコアの形式・入力テストあり | ESP32-P4対象ビルドはCI PASS。表示器上の実機試験 |
| 時刻保持 | Wi-Fi/SNTP と RTC を含む案がある | ネット断・停電時の要件、RTC部品と保持時間 |
| 電源 | USB-C給電を前提に安全構成を検討 | 5V電源、最大電流、保護、配線、温度 |
| 筐体・保護板 | 木製筐体、前面透明保護、前後整備を維持 | 素材、実寸、固定方法、CAD・加工図 |

## 作業の進め方

[状態記録](status-2026-10-21.md) は、会話上の報告とGitHubで検証できた内容を分ける。[作業一覧](worklist.csv) の受入条件を満たすまで、項目を完了扱いにしない。

`docs/01-requirements/requirements.yaml` は現行v0.20の要求台帳です。旧 `execution/tasks.csv`、`execution/progress.json` と48項目の証拠は、旧7軸設計の履歴として残し、新設計の進捗や合格根拠に流用しません。旧v0.8の全43要求と現行台帳の対応は[要求移行表](requirements-migration-v0.8-to-v0.20.csv)で整理済みです。
