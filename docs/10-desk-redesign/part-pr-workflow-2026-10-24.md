# Forest Guardian 部品単位PR・発注管理方針 (2026-10-24)

## 適用範囲
既存 main の文書・設計・履歴を削除／上書きせず、部品ごとの新規設計を追跡する。既存 `AGENTS.md` と `docs/01-requirements/requirements.yaml` を優先する。

## 設計原則
- 現行は単一モーター連動の装飾歯車。旧7軸資料を現行確定仕様としない。
- 部品単位または不可分アセンブリ単位でブランチとPRを作成する。
- 各寸法に出典と状態（FIXED / PROVISIONAL / OPEN / REJECTED / SUPERSEDED）を付す。
- 図面が描けることと製作発注できることを区別する。
- mainへのマージは製造発注許可ではない。購入・発注はユーザーの別途承認が必要。

## 先行順序
1. 参照ZIPの原本登録・出典監査（本PR）
2. ディスプレイ固定リング／保持アセンブリの設計（専用PR）
3. FG-B01 土台（専用PR）
4. FG-B02 波形装飾、柱、左右側板、天板、背面板（各専用PR）
5. 全体組立・干渉・保守性の統合検証

## ディスプレイ固定リングの発注ゲート
1. 採用型番を確認し、メーカー機構図と実機寸法（可能な限り）を照合する。
2. 既製品流用、一体型、分割型を、見た目・強度・コスト・交換性で比較する。
3. ガラスに過大な荷重をかけない保持方式を決定し、リング支持先を特定する。
4. STEP/STL、寸法付き2D図、材料、締結部品、組立手順を揃える。
5. 干渉、公差、造形方式、配線逃げ、着脱性をレビューし、外注先に加工可否を照会する。
6. PR承認・マージとは別に、見積もりと発注内容の明示承認を得る。
7. 納品後に受入検査を記録する。

## 各部品PRの最低条件
- 要求と依存インターフェース
- 寸法の根拠、未確定寸法、許容差
- CADソースおよびSTEP/STL（該当時）、日本語寸法図
- 部品表、加工／組立手順、保守手順
- 干渉・強度・製造性の検証結果と限界
- 発注可否は別欄に明記（初期値は NOT_AUTHORIZED）

## 本PRの完了条件
- 参照ZIPの**元バイト列**を保存しSHA-256を照合する。
- ZIP内ファイル一覧と各資料の現行／旧設計上の位置付けを記録する。
- 現行mainとの差分と矛盾を監査する。
- `python3 tests/check_design.py` を実行し結果を記録する。
- 上記未達の間はDraft PRを維持する。
