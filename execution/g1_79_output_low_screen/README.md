# G1-79 — 28相のHIGH-Z出力と10kΩプルダウンの定量検査

**設計成果物：既存G1-78（208端子/28相）の回路台帳の独立監査＋停止時入力電圧の「仮定値による」解析。** 製品回路を有効化せず、実機安全合格を宣言しない。G1-05/06はWORKING、19/48、製造0/6、SW11/14、G1-07 ERC/DRC OPENを維持。

## 重要な問題

G1-78 の SN74LVC244A 出力を HIGH-Z にしても、下流10kΩプルダウンだけで「モータードライバ端子は常にLOW」とは証明できない。モジュール内蔵のプルアップやリークで端子電圧は上がる。計算対象は **静的な理想DC抵抗網** に限定し、Ioff特性、起動・停止・VCC断の過渡、ESD、信号ノイズ、グランド断線、実際のモジュール型番・低入力しきい値 VIL(max)、実機での逆給電は一切未検証。

計算式（プルアップ抵抗が無い場合は 1/Rpu=0）：

    Vnode = (Vpu/Rpu + Isource) / (1/Rpu + 1/Rpd)

Isourceはドライバ入力などからノードに流れ込む仮定の正電流(A)。LOWの*仮定しきい値*を0.8Vとする例：

| 仮定条件 | 停止端子の算出電圧 | 仮のLOW条件 |
|---|---:|---|
| Vpu 5V, Rpu 10kΩ, Rpd 10kΩ, Isource 0 | 2.500V | 不合格 |
| Vpu 5V, Rpu 100kΩ, Rpd 10kΩ, Isource 0 | 0.455V | DC条件上のみ合格 |
| プルアップなし、Rpd 10kΩ、流入100µA | 1.000V | 不合格 |
| Vpu 5.25V, Rpu 9.5kΩ, Rpd 10.5kΩ、流入100µA | 3.255V | 不合格 |

**これら4条件は説明用の仮定であり、部品の実測値でもメーカー仕様でもない。** 0.8Vはサンプル低レベル判定値に過ぎず、製品採用の許容しきい値ではない。「仮のLOW条件に合格」と「安全に停止できる」は同義ではない。

## 実装・検証

- `screen.py`: G1-78 実208端子台帳を再読込し、28本全てのモジュール端子が独立10kΩプルダウン付きという配線登録を検査する。G1-77のU7.EN=GNDおよびU_ARM.Q孤立も確認。
- `test_screen.py`: 28本の各抵抗を1件ずつ除去する独立28回故障注入と、電圧モデル・不正引数の標準ライブラリ単体試験。
- 実行: `python3 -m unittest discover -s execution/g1_79_output_low_screen -p 'test_*.py' -v` および `python3 execution/g1_79_output_low_screen/screen.py`。
- 回路図原本は依然として配布済みZIPにあり、このCIは新しい製造回路図/ERC/HILを検査しない。**故障を検知したのは登録済みJSONの改変であって物理線の欠陥ではない。**

## 実測まで残る承認条件（全てHOLD）

1. 実装予定の全7軸モジュールの型番・入力電圧・内部プルアップ/プルダウン・VIL(max)/VIH(min)・漏れ電流をメーカー一次資料および実測で確認する。
2. 3.3V AON/5V Motor供給の正常・喪失・立上り・立下り・片電源条件でドライバ入力28本のVnodeをオシロで観測する。電源逆流/ESD電流限界も照合する。
3. 10kΩのまま採用できるかは測定した最大注入電流、最悪抵抗公差、モジュール入力VIL(max)を代入して判定する。解析だけで抵抗変更や配線製作を許可しない。
4. 実際の STOP, WDI, POR, PG、押しっぱなし再arm、バッファOE、U7.ENの独立フェイルセーフ経路と故障保持を製作前に別途設計・レビューする。
5. 正式KiCad ERC/PCB DRC、適正フットプリント、HIL故障注入、熱/EMI、製造承認6ゲートの実測完了までは全てHOLD。

**禁止事項を維持：** eFuse U7.ENを10kΩ経由GND以外につなげない。モーターへの通電・購入・加工・基板製作・書込み・mainへのマージは不可。
