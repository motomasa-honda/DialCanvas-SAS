# G1-81 — モーター実電圧監視 6-pin/16-pad 分離回路候補

**物理端子を指定した設計レビュー（未接続）**。TI TPS3808G01DBVR (DBV/SOT-23-6) adjustable 0.405V nominal supervisorを候補として、U7.3のオープンドレインPGとは別に、既存U7.6につながる5V_MOTOR出力電圧を抵抗分圧で検知する。G1-80では必要と判明した独立rail_validの**具体的な第一候補**である。

- U_RAIL_SV.1 RESET open drain → 10kΩから3V3_AONへプルアップされた仮のRAIL_OK_N_SUPERVISOR
- U_RAIL_SV.2 GND、.3 MR → 10kΩから3V3_AONへプルアップ（手動リセット入力を今回は使わない）、.4 CT OPEN候補（TI標準の約20ms release遅延）、.5 SENSE←5V_MOTOR 100kΩ/10kΩ分圧、.6 VDD←3V3_AON。100nF候補をVDD-GND間に追加
- 故障/低電圧ではRESET LOW、正常後は約20ms経過後に出力開放、外部抵抗でHIGHへ。**RESETは自己ラッチ機能を持たない**ため、運転中の異常履歴を保持するFFや独立起動期限タイマーは**別途必須**。

## 計算と検査（仮値）

SENSE reference nominal 0.405V、上抵抗100kΩ、下抵抗10kΩとした場合、VOUTの計算トリップ点は4.455V。抵抗だけ±1%を入れた例は約4.375–4.537V。**これは部品仕様に対して正式な最悪条件保証ではない**（VITの温度/精度、ヒステリシス、パワー供給、入力リーク、起動時間、実ドライバ許容電圧、実測なし）。製品の許容しきい値・抵抗値の確定を意味しない。

新しい nets_16.json に回路候補の**すべての16個の物理端子→7ネット**を記録し、TI DBVパッケージのピン番号、既存G1-77のU7.EN=GND、G1-78の全OE_HIGHに対する非干渉をチェック。意図的な10種類の誤配線注入を検出。G1-80のモデルは原本のまま、元140/208端子の物理結線を変更していない。

## 製造への接続を止めている未完了条件

1. 新回路はKiCad native図面ではなく**設計候補の物理ピン台帳**。6-pin footprint選択・ERC/DRCなし、実機未製作。モーター5Vと3V3が別タイミングで欠ける際、RESET pull-upの値が信用できるかHIL要検証。
2. CTの約20ms releaseは**起動期限500msを作る部品ではない**。独立タイムアウト回路とFAULT保持FF、両HIGH固着故障診断を未設計。PGとrail_validが両方正常固着すれば検出漏れの危険。
3. 既存TPS25947のPGTH（入力か出力の閾値を監視する方式・サフィックス）/EN/PG仕様のメーカー照合、対象モーターモジュールの駆動可能な最低電圧、基板逆給電確認が未完了。
4. STOP単一NC溶着、TPS3431 SET1無効化条件、POR同時立上り、28相の出力LOW未確定も以前からHOLD。
5. **eFuse U7.1 ENは10kΩでGND、SN74LVC244Aの/ OEはHIGH固定。** この候補RAIL_OKをつないでモーターへ通電することは禁止。
