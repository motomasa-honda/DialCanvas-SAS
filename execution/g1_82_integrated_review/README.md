# G1-82 — 364実端子の同一KiCadレビュー回路図（未製造）

- **成果物:** `forest_guardian_g1_82_review.kicad_sch`（KiCad 9 S-expression / A0）、364ピンの端子対ネット接続、98個の**仮想レビューシンボル**、元端子対応の `pin_map_364.json`、 `design_contract.json`、CI整合検証。これは**単一回路図へ既存140/208/16端子を物理ピン番号付きで可視化**した成果。旧原本の140/208/16-netlistsは**変更していない**。
- 新たな同一ネット接続は **GND共通 / 3V3_AON共通 / 5V_MOTOR共通** のみ。G1-78で異なる `VCC_3V3_AON` は3V3_AONと同じ常時3.3Vレールという**仮定の別名処理**。別電源の場合は分離しなければならない。
- その他のネットは B77__/B78__/B81__ を付けて**意図しない同名短絡を禁止**。G1-81モーターレール監視入力 `R_RAIL_TOP.1` はB77 `U7.6` と同じ5V_MOTORネット。G1-81の RESET信号はeFuse ENから隔離、G1-77 ARM_Qも隔離、G1-78各/OEは抵抗プルアップでHIGH固定（出力禁止）。
- 本図面では**全98個の部品がKiCad abstract pin-box**であり、TI製品の**正規グラフィックシンボル/ピン電気種別/フットプリントには置換していない**。KiCadの `on_board no` / `in_bom no` と空Footprintで発注・基板加工の誤用を防ぐ。各シンボル `FG_Source_Ref` と元端子マップで本来のメーカー端子番号を追跡できる。実物のメーカーpinout / footprints / ERC / PCB DRCは別途確認。
- **重要:** これは**元3ブロックをレールだけ統合した「電気接続の中間レビュー回路図」**であり、故障保持FF・物理起動期限タイマー・安全監視PG→eFuse/OEの稼働経路は**未接続**。これらを勝手に有効化することは禁止。

## 再現可能な検証

`check_integrated.py` は既存ソース JSON から期待する364ピンを再構築し、同梱のKiCad回路図に364本の同一ネットラベル・364配線セグメント・98個の元参照プロパティが存在すること、UUID一意性、括弧釣合い、GND/3V3/5V結合、eFuse EN/OEの無効条件を監査する。**KiCad本体によるパースやERCが成功したとは証明しない**。CIは外部ハードウェアなしで自動再実行する。
