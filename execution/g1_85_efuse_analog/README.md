# G1-85：TPS259474LRPW 外付け4系統を実端子で接続したKiCad回路レビュー

## この成果は単なる台帳ではない
G1-84で**純正KiCad9のXMLネットリスト検証に成功**した364実ピン/98レビュー記号/104ネットの図を完全コピーして、**５個の実際の受動素子候補（10端子）を追加**した独立した編集可能な `forest_guardian_g1_85_analog_review.kicad_sch`。G1-84原本は変更せず比較可能。合計**374物理端子・103部品記号・104ネット**。旧「単一接続の未完了4系統」にはそれぞれ電気的接続が入る。U7だけは抽象PAD10から**TPS259474LRPWのメーカー規定ピン番号・名称・電気種別を持つ正規端子相当の独自レビュー記号**へ置換し、既存G1-84の全EN/OE/PG系統を保存した。

## TI datasheet SLVSFC9C（2026年5月版）に基づく仮の計算値
- OVLO rising = VOV(R) × (Rtop+Rbottom)/Rbottom = 1.20×(47+12)/12 = **5.900V典型**。VOV(R) min1.183/max1.223V、抵抗公差±1%を合わせた範囲は**約5.725–6.110V**（入力漏れ・温度条件等の追加誤差なしの静的試算）。入力5V nominal→高電圧保護の候補、採用確定不可。
- ILM pin 9 `R_ILM = 3334/I_LIM` により 2.21kΩ → **約1.509A**の回路ブレーカー閾値 *典型試算*。7軸モーターと補機の電流・ピーク未測定、**7軸で運転できるとは主張しない**。最大使用電流、端子温度、UL認証の条件を別途確認。
- 3.3nF DVDT capacitor → `C(pF)=2000/SR(V/ms)` から SR ≈ **0.606V/ms**、nominal 5Vで立上り**約8.25ms**。出力総容量未測定で突入電流・過熱は未評価。実装するセラミックは温度特性とDCバイアスを含め再選択。
- 2.2nF ITIMER → `t(ms) = ΔV(V)×C(nF)/I(µA)`、ΔVtyp1.51V、Ityp1.8µAで**約1.846ms**。大電流短絡時の即応は別特性。過電流繰返しや温度範囲の最悪値は未評価。

> **CRITICAL:** これらはTI式で説明した「部品仮置き」であり安全・性能・実装温度の承認ではない。部品型番、電流定格、TPS259474Lの物理RPW footprint、基板クリアランス、発熱・電源/STOP異常試験は未実施。
