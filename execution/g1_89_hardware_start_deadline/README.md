# G1-89 — 電源起動監視タイマーの閾値修正（実KiCad候補、非通電）

## 既存回路の危険な不整合を解消

以前のG1-89ではTPS3808G01DBVRのMR（U33.3）をTPS259474L eFuseのEN/UVLOに直結していました。TI一次資料によると、TPS259474のEN有効化は1.183Vから起こり得る一方、TPS3808のMR HIGH保証はVDD=3.3Vなら2.31V以上です。したがって**モーター電源だけ有効となって起動タイマーが始まらない窓**があり、変更前の設計はそのまま稼働させられません。

今回は**回路端子の物理接続を次のように修正**します。

- **U33.3 MR_N → 3V3_AON**（U33.6 VDDと同じレール、通常動作中は常時HIGH）。
- **U33.5 SENSE → B89__EN_SENSE_DIV**（デジタルMRではなく高精度0.405VのアナログSENSEで本物のEN電圧を観測）。
- **R57=12kΩ±1%**を実eFuse EN（U14.1と同ネット）～SENSE間、**R58=10kΩ±1%**をSENSE～GND間。C32=1nFはこのSENSEに接続。**起動タイマCTは100kΩのR62で3V3_AONにプルアップ**するメーカー固定遅延モードへ変更。従来の68nF C30は撤去。
- J19廃止、RESET_NのR56は10kΩ→**100kΩ**へ値変更し、TIの遅延規格試験で用いた100kΩ負荷に合わせた。**R4=10kΩでENをGNDへ固定する既存安全措置と8本の/OE無効は維持。**

閾値の公称値は0.405×(1+12/10)=**0.891V**。TPS3808G01のVIT±2%、各抵抗±1%を組み合わせた最悪範囲は概ね0.864～0.919Vとなり、TPS259474の**EN立上り下限1.183Vより低い**。ゆえにENが実際にeFuseを有効化し得る前にSENSEがタイマ開始を検知する構成です。ただしコンデンサ、温度、SENSE漏れ電流、実EN駆動源・電源ランプはHILでの照合が必要であり**時間保証ではありません**。

U33からのRESET_N解除でMONITOR_ACTIVEがHIGHになり、G1-88のPG×独立5V健全性監視を有効にします。元PG信号に依存して監視を開始することはありません。

## 未完了と禁止事項

*TI TPS3808のCT→VDD固定遅延モード（100kΩ R62）は、メーカー仕様で180～420ms、代表値300ms。これはデータシート所定のRESET負荷・VDD・温度条件におけるIC単体の規格であり、回路全体の起動期限500ms保証とは別。* 実負荷・eFuse立上り時間・AON電源喪失中のロジック未定義、EN実駆動回路、故障遮断FETオン抵抗、PCBメーカーfootprint/ERC19件/DRC/実機HILは未完了。U33が3V3_AONをSENSEで監視しなくなったため、**AON独立ブラウンアウト検知の設計・検証が別途必要**。ENには追加した12k+10k分圧が抵抗負荷として並列接続されるため、将来駆動回路はR4と併せて3.3V時に約0.48mAのソース能力が必要。

G1-05/G1-06はWORKING、20/48 DONE_SCOPE、製造0/6。現物通電・購買・製造・書込み・mainマージは禁止。

## 68nF CT公称値から規格上限のある固定時間方式への変更

TI TPS3808 Rev.N §7.3.2にはCTを40k～200kΩ経由でVDDに接続する方法があり、§6.6ではRESET遅延が**180ms以上／300ms標準／420ms以下**と規定される。R62=100kΩはこの範囲の中央であり、外付コンデンサのばらつきやリークから独立。RESET_NのR56プルアップをTI規格試験の100kΩへ合わせた（実基板ではRESETピン容量・配線・入力漏れ・レール立上りの検証が残る）。本変更でU33のタイマー方式自体には500ms要求まで80msの最大時間差が生まれるが、eFuse電源立上り後の経路伝搬・入力遷移、実機故障応答を含む総時間の合格とはしない。
