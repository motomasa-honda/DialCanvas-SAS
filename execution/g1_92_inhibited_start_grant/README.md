# G1-92 — 正常時のeFuse起動許可回路を実配線（安全のため強制OFF維持）

## 何が未完成だったか
G1-91までは故障時のラッチ・遮断経路が存在しても、正常時にモーターeFuse ENへ実際に起動要求を与える回路が無かった。G1-80で定義された起動シーケンスを物理的に統合するため、3個のメーカー実端子付きゲートを追加した。

U39 SN74LVC1G08DBVR: B77__ARM_LATCH_Q_ISOLATED（実物U2.5）AND B77__QUAL_CLR_N（実物U21.2）。U40 SN74LVC1G04DBVR: B90__CUT_REQUEST_OR（実物U35.4、FAULT_Q または TRIP_ALL）を反転し、故障なしの条件を作る。U41 SN74LVC1G08DBVR: (ARM_AND_HEALTH) AND (NO_FAULT) を B92__RAIL_GRANT_LOGIC として生成する。

**PGや5V_MOTORは起動前LOWなので、起動許可の条件へ使用しない。** PG/5Vの監視と起動後タイムアウトは既存G1-88/G1-89/G1-91で別系統。7軸28相のRUN許可はまだ接続しない。

## 同じ実ENへ配線したが、誤通電させない二重の電気的上限制限
U41.4 → R66=68kΩ ±1% → B92__GRANT_LIMIT_STAGE → R68=68kΩ ±1% → 既存 **U14.1 TPS259474 EN/UVLO** へ実配線。元のR4=10kΩ GNDプルダウンに加えてR67=10kΩ GNDプルダウンを増設。U33起動監視のR57=12k/R58=10k分圧も実ENに並列接続されている。

最悪条件を保守的に見積もって、3.3V_AON最高3.6V、抵抗±1%、R4およびR67がともに断線、さらにはR66またはR68のうち一方が短絡しても、残る68kΩとR57+R58によってENは約0.893V以下。eFuse EN最低有効化閾値1.183Vより低い。正常時はさらに低く、実回路ではモーターを起動できない。これは**安全保持を優先する仮の電流制限値**であり、運用前に抵抗を下げたり、プルダウンを取り除くことを許可しない。部品の追加は運用承認ではない。

R4/R67二本とR66/R68二段を実KiCadの個別部品として作図。3つのロジックICに個別100nFデカップリングC39～C41を配置。U40メーカーNCピンはKiCadの本物のno_connect。前段552端子を一切変更せず、新規27端子・9部品、計579端子/168部品。CIはKiCad9 XML/SVG/ERCと電圧上限不等式を検証する。

## 正式G1-05/G1-06が未完了の理由
本回路は**電圧上限により実際のモータを起動できないレビュー版**。今後、指定の物理スイッチ停止経路、WDIパルス、3.3V喪失/5V残存、8本OEのRUN+PG+5V連動、エネルギー残留とeFuse EN安全しきい値、PCBフットプリントとERC19件解消、基板DRC、単一故障・HIL試験を実行してから、初めて機能動作版のEN分圧/抵抗値の再設計可否を判断する。**メーカー部品の設計候補を接続したことだけではG1-05/G1-06をDONEにしない。**
