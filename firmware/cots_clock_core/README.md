# DialCanvas 時計針コア

ESP-IDF/LVGLへ組み込む時計針角度計算、入力処理、ステッパー周期生成、DS3231のUTC変換の依存なしCコア。ホスト上でビルドし、時刻境界、小数秒補間、ロータリーエンコーダーの遷移方向、文字盤インデックスの巡回、ステッパーSTEP周期の平均値、RTCカレンダーの有効範囲を検証できる。

## 契約

- 入力はローカル時刻の時・分・秒・ミリ秒。RTC/SNTPからの時刻取得とタイムゾーン変換は呼び出し側が担当する。
- 出力角は12時を0度、時計回りを正方向とし、範囲は`[0, 360)`。
- 秒の小数部を分針・時針へ連続反映する。針の更新周期は呼び出し側が決める。
- 不正な時刻またはNULL出力では`false`を返し、出力構造体は変更しない。
- エンコーダー遷移関数は一回のGray-code遷移だけを数え、2ビット同時変化など無効遷移を捨てる。文字盤インデックス関数はリスト端で巡回する。
- 文字盤フォルダー名は1〜32文字のASCII英数字、`_`、`-`だけを許可し、`.`や区切り文字によるパストラバーサルを拒否する。32件を超えるカタログは名前順の先頭32件を残すための挿入位置もコアで計算し、カード上の列挙順に依存しない。
- 文字盤設定形式は[`dial.schema.json`](dial.schema.json)。表示中心は画像幅/高さ比、針長は800px画像幅に対する0〜0.5の比率（0.5で表示円の半径）、太さは1〜32px、色は`#RRGGBB`。編集例は[`examples/Forest/dial.json`](examples/Forest/dial.json)。
- DS3231コアはUTC秒と7個のカレンダーレジスターを相互変換する。2000-01-01から2099-12-31までを扱い、OSF、BCD不正、範囲外日付を拒否する。I²Cアクセス、`settimeofday`、SNTP連携はアプリ側の責務。
- ステッパー周期生成器はfull-step数、マイクロステップ分割、milli-rpmを受け、整数余りを配分したSTEP間隔をµs単位で返す。200step/rev、1/8、1.600rpmでは23,437/23,438µsを配分する。これは間隔計算だけであり、GPIO、EN、安全遮断、モーター駆動をしない。

## ホスト検証

```sh
cmake -S firmware/cots_clock_core -B /tmp/dialcanvas-clock-core-build
cmake --build /tmp/dialcanvas-clock-core-build
ctest --test-dir /tmp/dialcanvas-clock-core-build --output-on-failure
```

このコアのテストは計算式と境界連続性、エンコーダー遷移表、インデックス巡回、文字盤名の安全性と名前順カタログ上限、2,560ステップ/60秒となる平均STEP間隔、DS3231のUTC往復変換・12時間形式・うるう日・OSF/不正データ拒否、および2000〜2099年の各日を通す往復確認を行う。GPIO配線/チャタリング、LCD描画、LVGLフレーム周期、microSD/JPEG、I²Cアクセス、NTP/RTC統合、PSRAM使用量、電流、トルク、騒音、実機の見た目は検証していない。表示アプリに組み込んだ後、3.4C実機で30fps最低/60fps目標の受入を行う。
