# FG-D01 ディスプレイ前面分割リング

**設計段階:** PROVISIONAL。**製作・発注:** NOT_AUTHORIZED。

## 今回の構成判断
表示器本体は既存の4本腕キャリアで支持する。追加する左右2分割リングは**表示器を押さえる構造部品ではなく、前面の意匠トリム**として扱う。ガラスを挟んだり押したりしない。

既存ベースラインの前面透明ガードは連続板であり、背面z=0、前面z=-3mm。表示器ガラス前面はz=+1.5mm候補。従ってトリムは透明ガードの**観察者側**（z=-5〜-3mm）に置く方向を採用する。表示器との名目z方向距離は4.5mmで、透明ガード3mmが間に入る。

**注意:** このリングを前面ガードに直接接着する設計は未承認。固定先は透明板そのものではなく、将来設計するガード押さえ縁／取り外し可能な機械支持部とする方針。支持点がまだ存在しないため、現段階では「固定リング完成」ではない。

## 寸法候補
- リング外径119mm、内径113.4mm、見付幅2.8mm、厚み2mm。
- 左右2分割、合わせ目0.8mm。
- ガラス最大外径112.6mmに対して内径は直径0.8mm大きい。ただし**前面ガードで隔てる設計**なので、これをガラスとの直接嵌合公差として用いない。
- レンズ視野最大径88.4mmに対して内径113.4mm。表示を覆わないが、透明ガードの反射や画角は未評価。
