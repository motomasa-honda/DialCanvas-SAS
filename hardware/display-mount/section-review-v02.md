# FG-D01 断面・取付方針 v0.2

状態: PROVISIONAL。発注: NOT_AUTHORIZED。

## 今回の決定
表示器の荷重は既存4本腕キャリアが受ける。リングはガラス押圧式の固定具ではなく、前面ガードの外側に配置する**装飾トリム**として検討する。これにより表示器とリングの直接接触を避けられる。前面ガード自体は既存構想どおり周縁捕捉・着脱式押さえ縁で保持する。

注意: 本部品を「表示器固定リング」と呼ぶ場合も、表示器を実際に固定するのは既存キャリアである。リング単体で表示器を保持できると説明しない。

## z断面（暫定、mm）
| 構成 | z範囲 | 出典/状態 |
|---|---|---|
| 装飾リング | -5.0 ～ -3.0 | 新規候補 |
| 透明前面ガード | -3.0 ～ 0.0 | 現行ベースラインの候補 |
| ガードとガラスの空間 | 0.0 ～ 1.5 | 名目1.5mm |
| 表示器前面 | 1.5 | 既存候補 |
| 表示器奥行包絡 | 1.5 ～ 17.0 | 既存候補 |
| キャリア | 19.0 ～ 22.0 | 既存候補 |
| 支持板A | 29.0 ～ 37.0 | 既存候補 |

リングがガード外面に置かれる場合、リングはガラスに直接触れない。ただしガード外面への取り付け方法が未確定であり、図面上の面接触は接着仕様を意味しない。

## 正面形状候補
外径119.0、内径113.4、厚さ2.0、左右2分割、合わせ目全幅0.8。内径はガラス最大径112.6より0.8大きいが、ガラスとのクリアランスはz方向に隔てられるため、同心精度よりもガード上の見た目と位置決めが課題となる。

## 重要な設計上の未決定
- 外径119mm・見付幅2.8mmでは、通常のねじやクリップの固定余地が不足する。**ネジ固定可能とみなさない**。
- ガード外面への剥離可能な薄膜接着、ガード周縁まで延ばす隠し支持脚、またはリングを前面押さえ縁と一体化する3方式を比較する。
- 剥離式はガード表面の傷・糊残り・経年剥離の懸念があるため、現段階では未採用。
- ガード前面へ2mm突出するとケース前枠との干渉があり得る。ケース前枠・波形下辺の位置を次工程で断面確認する。
- 分割リングを同心に保持するための位置決め基準、組立順、隙間公差を定義する。

## 次の完了条件
1. 前面ガード押さえ縁と波形前枠の輪郭・位置をCAD上で確認。
2. 上記3方式から取付方式を一つ選定。
3. ねじ/クリップ/接着面を含む完成形状と公差をCAD化。
4. 2D寸法図・STL/STEP・BOM・検査基準を整備。

本v0.2は断面干渉を避けるための配置候補であり、造形データや発注指示ではない。
