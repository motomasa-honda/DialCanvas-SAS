# Phase74 — 5V supervision + NC STOP review, **NOT a powered motor safety circuit**

Base: Phase73 D7-protected 7-axis independently replaceable A-plan, actual Phase73 ESP32-P4 heartbeat 80ms candidate build PASS (not flashed). **Main is unchanged; PR #2 must remain Draft.**

## What is materially new

Added **TPS3808G50DBVR** (5V nominal rail supervisor, SOT-23-6), and NC STOP input to the Phase73 qualification-clear topology:
- Pins: RESET_N=1 (active LOW open-drain), GND=2, MR_N=3, CT=4, SENSE=5, VDD=6.
- VDD from 3V3_AON; SENSE observing 5V_RAW; **nominal threshold 4.65V** (not exactly 5V). Operating constraints incl. sense at 5V with supply at 3.3V require real electrical and vendor review.
- NC STOP J_STOP.1 from 3V3_AON; J_STOP.2 into MR_N with 10k pulldown to GND; STOP opened (or broken wire) nominally asserts low reset. The contact's actual wiring, debounce and noise are NOT tested.
- New RESET_N with its separate 10k pullup joins open-drain TPS3431 WDO/3V3 supervisor RESET_N at `QUAL_CLR_N`, which clears both Phase73 2-edge FFs.
- Source-of-truth review extension: [`stop-5v-contract.json`](./stop-5v-contract.json). Static CI validates total **71 uniquely assigned terminals / 24 nets**, eight rejected wiring mutations and 512 abstract fault truth cases. The fuller *integrated Phase74 handoff ZIP* contains a native-format KiCad partial schematic generated by the verified Phase73 generator and 17 Python host unit tests (16,128 deterministic randomized input steps).

## Critical limitations and new hazards

1. **STOP is single-channel.** A short from STOP sense to the 3.3V rail or welded contact looks healthy; no fault detection. Fault injection on actual harness is required, perhaps a dual-channel anti-short contact.
2. RESET_N recovering after a fault only resets FFs. **No physical retained TRIP latch, no guaranteed manual rearm**, and GPIO heartbeat can re-qualify two edges automatically. The companion model includes a required *manual release-then-press* and ARM LOW, but it is **NOT wired**.
3. **TPS259474LRPW U7 EN remains physically LOW** through 10k pulldown, without any approved drive. Its PG is not an FLT output and must be qualified AFTER motor rail startup without permitting unsafe motor motion. Second independent motor gate, PG watchdog / post-start fault latch, and eFuse ILM/ITIMER/DVDT/OVLO components missing.
4. No real KiCad ERC/DRC run or complete component footprints. No physical rail thresholds, short/open/weld, WDO jitter, stuck watchdog, 5V/3V3 brownout, 7-axis tests. **Do not fabricate/energize/flash hardware.**

**Current release state: manufacturing gates 0/6, software evidence 11/14 (SW09/12/14 open).** The CI PASS, if observed, is **only static verification** and must not change these counts.
